# 模型架构总览

模型架构决定特征如何流动、融合和压缩。CV 中最重要的架构线索是 CNN、Transformer 和各种混合结构。

## 选择架构的标准

- 数据规模：小数据更偏向 CNN，大数据预训练更适合 Transformer。
- 推理约束：移动端优先 MobileNet、ShuffleNet、轻量 YOLO。
- 任务类型：检测和分割需要多尺度特征，不只看分类精度。
- 可解释性：CNN 的局部性更直观，Transformer 的注意力更适合关系分析。

## 与任务的关系

- 分类：骨干网络输出全局语义。
- 检测：骨干 + neck 输出多尺度特征。
- 分割：需要保留空间分辨率并恢复像素级预测。
- 3D：点云、体素、隐式场需要专门的数据结构和网络。
