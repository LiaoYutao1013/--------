# 训练技巧总览

训练技巧决定模型能不能稳定收敛、泛化到新数据，并在有限算力下达到可用性能。

## 四类核心技巧

| 类型 | 代表方法 | 解决的问题 |
|------|----------|------------|
| 数据增强 | Flip、Crop、ColorJitter、Mixup、CutMix、Mosaic | 数据不足、过拟合、鲁棒性弱 |
| 优化器 | SGD、Momentum、Adam、AdamW | 梯度更新效率和稳定性 |
| 正则化 | Weight Decay、Dropout、BatchNorm、Label Smoothing | 降低过拟合 |
| 损失函数 | Cross Entropy、Focal Loss、IoU/GIoU/CIoU、Dice Loss | 让优化目标贴近任务指标 |

## 常见训练流程

```text
数据清洗
  ↓
数据增强与归一化
  ↓
选择 backbone / head
  ↓
设置损失函数
  ↓
优化器 + 学习率调度
  ↓
验证集监控与错误分析
```

## CV 任务中的重点

- 分类：交叉熵、Label Smoothing、Mixup/CutMix。
- 检测：Focal Loss、IoU 系列损失、Mosaic、多尺度训练。
- 分割：Dice Loss、Focal Loss、类别不平衡处理。
- 小目标：高分辨率、强增强、FPN/PAN、多尺度推理。

## 实验记录建议

每次实验至少记录：
- 数据版本和增强策略
- 模型结构和预训练权重
- 输入尺寸、batch size、epoch
- 优化器、学习率、weight decay
- 主指标和失败案例
