# 摄像头视图绘制与标注

本笔记专门用于记录如何在摄像头实时画面上绘制图形、文字、标注框、轨迹，以及与 OpenCV 可视化相关的实用技巧。

## 主要内容

- OpenCV 摄像头读取与实时显示
- 在视频帧上绘制基本几何图形
  - 线段、矩形、圆、椭圆、多边形
- 绘制文本与字体样式
  - 字体、颜色、粗细、抗锯齿
- 透明遮罩与半透明叠加
- 目标检测/跟踪结果画框与标签
- 坐标系与像素位置映射
- 鼠标交互与点击标注
- 性能优化与帧率控制

## 参考函数

- `cv2.VideoCapture`
- `cv2.imshow`
- `cv2.rectangle`
- `cv2.circle`
- `cv2.line`
- `cv2.polylines`
- `cv2.putText`
- `cv2.addWeighted`
- `cv2.setMouseCallback`

## 实用示例

### 在摄像头实时画面中绘制文字与矩形

```python
import cv2

cap = cv2.VideoCapture(0)
while True:
    ret, frame = cap.read()
    if not ret:
        break

    cv2.rectangle(frame, (50, 50), (250, 200), (0, 255, 0), 2)
    cv2.putText(frame, 'Camera Overlay', (60, 120), cv2.FONT_HERSHEY_SIMPLEX,
                0.8, (255, 255, 255), 2, cv2.LINE_AA)

    cv2.imshow('Camera View', frame)
    if cv2.waitKey(1) & 0xFF == 27:
        break

cap.release()
cv2.destroyAllWindows()
```

### 半透明遮罩与叠加信息

```python
import cv2

cap = cv2.VideoCapture(0)
while True:
    ret, frame = cap.read()

    overlay = frame.copy()
```

### 鼠标事件与坐标标注

```python
import cv2

points = []

def on_mouse(event, x, y, flags, param):
    if event == cv2.EVENT_LBUTTONDOWN:
        points.append((x, y))

cv2.namedWindow('Mouse Demo')
cv2.setMouseCallback('Mouse Demo', on_mouse)

cap = cv2.VideoCapture(0)
while True:
    ret, frame = cap.read()
    if not ret:
        break

    for p in points:
        cv2.circle(frame, p, 5, (0, 255, 255), -1)
        cv2.putText(frame, f'{p}', (p[0] + 10, p[1] - 10),
                    cv2.FONT_HERSHEY_SIMPLEX, 0.5, (255, 255, 255), 1)

    cv2.imshow('Mouse Demo', frame)
    if cv2.waitKey(1) & 0xFF == 27:
        break

cap.release()
cv2.destroyAllWindows()
```

```python
import cv2

frame = cv2.imread('example.jpg')
# 这里假设 detection_results 是 [(x1, y1, x2, y2, score, label), ...]

```

## 目标轮廓检测与描边

目标轮廓提取常用于从二值图像、分割结果或边缘图中找出目标轮廓，然后将它直接绘制到原图上。基本流程：

1. 灰度化 + 高斯模糊降噪
2. 二值化 / Canny 边缘检测
3. `cv2.findContours` 提取轮廓
4. 根据面积过滤噪声
5. 用 `cv2.drawContours` 或外接矩形 `cv2.boundingRect`/`cv2.minAreaRect` 绘制目标大致轮廓

### 轮廓描边示例

```python
import cv2

image = cv2.imread('example.jpg')
gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
blur = cv2.GaussianBlur(gray, (5, 5), 0)
ret, thresh = cv2.threshold(blur, 100, 255, cv2.THRESH_BINARY_INV + cv2.THRESH_OTSU)

contours, hierarchy = cv2.findContours(thresh, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)

for cnt in contours:
    area = cv2.contourArea(cnt)
    if area < 500:
        continue
    cv2.drawContours(image, [cnt], -1, (0, 255, 0), 2)

cv2.imshow('Contours', image)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

### 用外接矩形框出目标大致轮廓

```python
import cv2

image = cv2.imread('example.jpg')
gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
blur = cv2.GaussianBlur(gray, (5, 5), 0)
ret, thresh = cv2.threshold(blur, 120, 255, cv2.THRESH_BINARY)

contours, hierarchy = cv2.findContours(thresh, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)

for cnt in contours:
    area = cv2.contourArea(cnt)
    if area < 800:
        continue
    x, y, w, h = cv2.boundingRect(cnt)
    cv2.rectangle(image, (x, y), (x + w, y + h), (255, 0, 0), 2)
    cv2.putText(image, f'Area:{area:.0f}', (x, y - 10), cv2.FONT_HERSHEY_SIMPLEX,
                0.5, (255, 0, 0), 1, cv2.LINE_AA)

cv2.imshow('Bounding Boxes', image)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

### 近似轮廓与最小外接矩形

```python
import cv2
import numpy as np

image = cv2.imread('example.jpg')
gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
blur = cv2.GaussianBlur(gray, (5, 5), 0)
ret, thresh = cv2.threshold(blur, 100, 255, cv2.THRESH_BINARY)

contours, hierarchy = cv2.findContours(thresh, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)

for cnt in contours:
    area = cv2.contourArea(cnt)
    if area < 800:
        continue
    epsilon = 0.01 * cv2.arcLength(cnt, True)
    approx = cv2.approxPolyDP(cnt, epsilon, True)
    box = cv2.minAreaRect(cnt)
    box_pts = cv2.boxPoints(box)
    box_pts = np.int0(box_pts)
    cv2.drawContours(image, [approx], -1, (0, 255, 255), 2)
    cv2.drawContours(image, [box_pts], -1, (0, 0, 255), 2)

cv2.imshow('Approx & MinAreaRect', image)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

### 常见技巧

- `cv2.RETR_EXTERNAL` 只提取最外层轮廓，适合独立目标。
- `cv2.CHAIN_APPROX_SIMPLE` 能压缩轮廓点数，降低计算与存储成本。
- `cv2.boundingRect` 给出轴对齐包围盒，`cv2.minAreaRect` 给出旋转最小包围矩形。
- 复杂背景下先用颜色分割、语义分割或背景差分得到干净二值目标区域。
- 按面积、周长过滤小噪声轮廓，避免误描边。

### 基于边缘检测的实时目标轮廓描绘

以下示例演示如何使用摄像头实时捕获图像，基于 Canny 边缘检测提取目标轮廓，并在原始画面上绘制轮廓与外接矩形。可用于实时对象轮廓预览或简单运动目标追踪。

```python
import cv2

cap = cv2.VideoCapture(0)

while True:
    ret, frame = cap.read()
    if not ret:
        break

    gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
    blur = cv2.GaussianBlur(gray, (5, 5), 0)
    edges = cv2.Canny(blur, 50, 150)

    contours, _ = cv2.findContours(edges, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
    for cnt in contours:
        area = cv2.contourArea(cnt)
        if area < 300:
            continue

        # 绘制轮廓
        cv2.drawContours(frame, [cnt], -1, (0, 255, 0), 2)

        # 绘制目标大致包围矩形
        x, y, w, h = cv2.boundingRect(cnt)
        cv2.rectangle(frame, (x, y), (x + w, y + h), (255, 0, 0), 2)

    cv2.imshow('Edge Contour Overlay', frame)
    cv2.imshow('Canny Edges', edges)

    if cv2.waitKey(1) & 0xFF == 27:
        break

cap.release()
cv2.destroyAllWindows()
```

> Tip: 如果目标边缘不明显，可先用自适应阈值或光流辅助检测，再结合轮廓绘制提高实时效果。

## 边框动态高亮

### 闪烁边框示例

```python
import cv2
import time

cap = cv2.VideoCapture(0)
frame_count = 0
while True:
    ret, frame = cap.read()
    if not ret:
        break

    # 动态闪烁边框
    color = (0, 255, 0) if frame_count % 20 < 10 else (0, 0, 255)
    thickness = 3 if frame_count % 20 < 10 else 1

    cv2.rectangle(frame, (50, 50), (250, 200), color, thickness)
    cv2.putText(frame, 'Alert Zone', (60, 120), cv2.FONT_HERSHEY_SIMPLEX,
                0.8, color, 2, cv2.LINE_AA)

    cv2.imshow('Dynamic Highlight', frame)
    if cv2.waitKey(1) & 0xFF == 27:
        break

    frame_count += 1

cap.release()
cv2.destroyAllWindows()
```

### 渐变颜色边框

```python
import cv2
import numpy as np

cap = cv2.VideoCapture(0)
frame_count = 0
while True:
    ret, frame = cap.read()
    if not ret:
        break

    # 渐变颜色 (红色到绿色)
    intensity = int(127.5 * (1 + np.sin(frame_count * 0.1)))
    color = (0, intensity, 255 - intensity)

    cv2.rectangle(frame, (100, 100), (300, 250), color, 3)
    cv2.putText(frame, 'Gradient Border', (110, 170), cv2.FONT_HERSHEY_SIMPLEX,
                0.7, color, 2, cv2.LINE_AA)

    cv2.imshow('Gradient Highlight', frame)
    if cv2.waitKey(1) & 0xFF == 27:
        break

    frame_count += 1

cap.release()
cv2.destroyAllWindows()
```

## 常见问题

- `cv2.putText` 文字不清晰：请使用 `cv2.LINE_AA` 并调整字体大小和线宽。
- 颜色错位/不对：OpenCV 默认使用 BGR 顺序，写入颜色时要注意 `(B, G, R)`。
- 图形位置不正确：框选坐标要与图像坐标一致，`(x, y)` 对应 `(列, 行)`。
- 文本被裁剪或重叠：预留足够位置，或者在文本背景上做半透明遮罩。
- 实时画面卡顿：避免在循环中频繁创建大对象、减少不必要的绘制、使用更小分辨率。
- 窗口无响应：`cv2.waitKey` 需要在循环中调用，否则窗口无法刷新和响应键盘事件。
- 摄像头无法打开：检查 `VideoCapture(0)` 参数是否正确，或改用 `VideoCapture(1)` / 视频文件路径。

## 建议

1. 在真实摄像头图像上调试颜色、线宽与文字大小。
2. 使用半透明遮罩提升提示信息可读性。
3. 将标注绘制与图像处理分离，保持代码结构清晰。
4. 先在静态图像上验证单个绘制函数，再迁移到实时视频循环中。
5. 若需对齐多种标注，统一使用同一坐标系和像素基准。
