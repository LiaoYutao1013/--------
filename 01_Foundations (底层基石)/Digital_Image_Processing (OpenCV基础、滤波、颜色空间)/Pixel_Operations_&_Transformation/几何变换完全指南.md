# 📐 几何变换完全指南

## 概述

几何变换（Geometric Transformation）是图像处理的基础操作，用于改变图像的空间排列。包括旋转、缩放、平移、透视变换等。这些变换广泛应用于：
- 图像对齐和配准
- 数据增强
- 图像恢复
- 医学成像

## 1. 核心概念

### 1.1 仿射变换 vs 透视变换

#### 仿射变换（Affine Transformation）
保持平行线仍为平行线。使用 2×3 矩阵表示：

$$\begin{bmatrix} x' \\ y' \end{bmatrix} = \begin{bmatrix} a_{11} & a_{12} \\ a_{21} & a_{22} \end{bmatrix} \begin{bmatrix} x \\ y \end{bmatrix} + \begin{bmatrix} b_1 \\ b_2 \end{bmatrix}$$

或简化为：
$$\begin{bmatrix} x' \\ y' \\ 1 \end{bmatrix} = \begin{bmatrix} a_{11} & a_{12} & b_1 \\ a_{21} & a_{22} & b_2 \\ 0 & 0 & 1 \end{bmatrix} \begin{bmatrix} x \\ y \\ 1 \end{bmatrix}$$

#### 透视变换（Perspective Transformation）
允许平行线在无穷远处相交。使用 3×3 矩阵表示：

$$\begin{bmatrix} x' \\ y' \\ 1 \end{bmatrix} = \begin{bmatrix} h_{11} & h_{12} & h_{13} \\ h_{21} & h_{22} & h_{23} \\ h_{31} & h_{32} & h_{33} \end{bmatrix} \begin{bmatrix} x \\ y \\ 1 \end{bmatrix}$$

**区别对比**：

| 特性 | 仿射变换 | 透视变换 |
|------|---------|---------|
| **矩阵大小** | 2×3 | 3×3 |
| **自由度** | 6 | 8 |
| **平行性** | 保持 | 不保持 |
| **使用场景** | 旋转、缩放、平移、倾斜 | 建筑、文本、 document 扫描 |
| **配准点数** | 最少 3 个 | 最少 4 个 |

### 1.2 插值方法

变换过程中需要对新像素进行插值：

| 方法 | 计算复杂度 | 效果 | 应用场景 |
|------|---------|------|---------|
| **最近邻** | 极低 | 低 | 分类图（二值图） |
| **双线性** | 低 | 中 | 实时应用 |
| **双三次** | 中 | 高 | 高质量输出 |
| **Lanczos** | 高 | 最高 | 专业应用 |

## 2. 基础变换详解

### 2.1 平移（Translation）

将图像移动 $(t_x, t_y)$ 距离：

$$\begin{bmatrix} x' \\ y' \end{bmatrix} = \begin{bmatrix} 1 & 0 \\ 0 & 1 \end{bmatrix} \begin{bmatrix} x \\ y \end{bmatrix} + \begin{bmatrix} t_x \\ t_y \end{bmatrix}$$

**矩阵形式**：
$$M = \begin{bmatrix} 1 & 0 & t_x \\ 0 & 1 & t_y \end{bmatrix}$$

```python
import cv2
import numpy as np

# 平移矩阵：右移 100 像素，下移 50 像素
rows, cols = img.shape[:2]
M = np.float32([[1, 0, 100],
                [0, 1, 50]])

# 应用变换
result = cv2.warpAffine(img, M, (cols, rows))
```

### 2.2 旋转（Rotation）

绕图像中心旋转 $\theta$ 角度：

$$M = \begin{bmatrix} \cos\theta & -\sin\theta & (1-\cos\theta)c_x + \sin\theta \cdot c_y \\ \sin\theta & \cos\theta & (1-\cos\theta)c_y - \sin\theta \cdot c_x \end{bmatrix}$$

其中 $(c_x, c_y)$ 是旋转中心。

**实现方法 1：OpenCV 自动计算**
```python
# 获取旋转矩阵
center = (cols // 2, rows // 2)
angle = 45  # 顺时针 45 度
scale = 1.0  # 缩放因子
M = cv2.getRotationMatrix2D(center, angle, scale)

# 应用变换
result = cv2.warpAffine(img, M, (cols, rows))
```

**实现方法 2：手动计算**
```python
def rotate_image(img, angle, scale=1.0):
    rows, cols = img.shape[:2]
    center = (cols // 2, rows // 2)
    
    # 角度转弧度
    rad = np.radians(angle)
    
    # 旋转矩阵
    cos_a = np.cos(rad) * scale
    sin_a = np.sin(rad) * scale
    
    dx = (1 - cos_a) * center[0] - sin_a * center[1]
    dy = sin_a * center[0] + (1 - cos_a) * center[1]
    
    M = np.float32([[cos_a, -sin_a, dx],
                    [sin_a, cos_a, dy]])
    
    return cv2.warpAffine(img, M, (cols, rows))
```

### 2.3 缩放（Scaling）

改变图像大小：

$$\begin{bmatrix} x' \\ y' \end{bmatrix} = \begin{bmatrix} s_x & 0 \\ 0 & s_y \end{bmatrix} \begin{bmatrix} x \\ y \end{bmatrix}$$

```python
# 方法 1：指定比例
scaled = cv2.resize(img, None, fx=2.0, fy=2.0, 
                    interpolation=cv2.INTER_LINEAR)

# 方法 2：指定目标尺寸
scaled = cv2.resize(img, (640, 480),
                    interpolation=cv2.INTER_LINEAR)

# 方法 3：等比缩放
scale_percent = 50
width = int(img.shape[1] * scale_percent / 100)
height = int(img.shape[0] * scale_percent / 100)
scaled = cv2.resize(img, (width, height))
```

## 3. 高级变换

### 3.1 仿射变换（Affine）

从 3 个对应点自动计算变换矩阵：

```python
# 定义源点和目标点
pts1 = np.float32([[50, 50], [200, 50], [50, 200]])
pts2 = np.float32([[10, 100], [200, 50], [100, 250]])

# 计算仿射变换矩阵
M = cv2.getAffineTransform(pts1, pts2)

# 应用变换
result = cv2.warpAffine(img, M, (img.shape[1], img.shape[0]))
```

**原理**：
给定 3 个点对：
- $(x_1, y_1) \to (x_1', y_1')$
- $(x_2, y_2) \to (x_2', y_2')$  
- $(x_3, y_3) \to (x_3', y_3')$

求解线性方程组：
$$\begin{bmatrix} x_i' \\ y_i' \end{bmatrix} = M \begin{bmatrix} x_i \\ y_i \\ 1 \end{bmatrix}$$

### 3.2 透视变换（Perspective）

从 4 个对应点自动计算变换矩阵（Document Scanning 常用）：

```python
# 定义源点和目标点（四边形）
pts1 = np.float32([[0, 0], [640, 0], [0, 480], [640, 480]])
pts2 = np.float32([[10, 10], [630, 20], [5, 470], [635, 465]])

# 计算透视变换矩阵
M = cv2.getPerspectiveTransform(pts1, pts2)

# 应用变换
result = cv2.warpPerspective(img, M, (img.shape[1], img.shape[0]))
```

**Document Scanning 完整流程**：
```python
def scan_document(img):
    """检测文档并进行透视变换"""
    
    # 1. 灰度 + 边缘检测
    gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
    blurred = cv2.GaussianBlur(gray, (5, 5), 0)
    edges = cv2.Canny(blurred, 50, 150)
    
    # 2. 检测轮廓
    contours, _ = cv2.findContours(edges, cv2.RETR_EXTERNAL, 
                                     cv2.CHAIN_APPROX_SIMPLE)
    
    # 3. 找最大矩形
    largest = max(contours, key=cv2.contourArea)
    peri = cv2.arcLength(largest, True)
    approx = cv2.approxPolyDP(largest, 0.02 * peri, True)
    
    # 4. 获取四个角点
    pts = approx.reshape(4, 2)
    rect = order_points(pts)  # 排序为 TL, TR, BR, BL
    
    # 5. 计算目标尺寸
    (tl, tr, br, bl) = rect
    widthA = np.sqrt((br[0] - bl[0])**2 + (br[1] - bl[1])**2)
    widthB = np.sqrt((tr[0] - tl[0])**2 + (tr[1] - tl[1])**2)
    width = max(int(widthA), int(widthB))
    
    heightA = np.sqrt((tr[0] - br[0])**2 + (tr[1] - br[1])**2)
    heightB = np.sqrt((tl[0] - bl[0])**2 + (tl[1] - bl[1])**2)
    height = max(int(heightA), int(heightB))
    
    # 6. 透视变换
    dst = np.array([[0, 0], [width, 0], [width, height], [0, height]],
                   dtype=np.float32)
    M = cv2.getPerspectiveTransform(rect, dst)
    warped = cv2.warpPerspective(img, M, (width, height))
    
    return warped

def order_points(pts):
    """排序四边形顶点为 TL, TR, BR, BL"""
    s = pts.sum(axis=1)
    rect = np.zeros((4, 2), dtype=np.float32)
    rect[0] = pts[np.argmin(s)]  # TL (最小和)
    rect[2] = pts[np.argmax(s)]  # BR (最大和)
    
    diff = np.diff(pts, axis=1)
    rect[1] = pts[np.argmin(diff)]  # TR (最小差)
    rect[3] = pts[np.argmax(diff)]  # BL (最大差)
    
    return rect
```

### 3.3 图像配准（Image Registration）

使特征点对齐：

```python
# 使用特征点的配准
def align_images(img1, img2):
    """使用 SIFT 特征进行图像配准"""
    
    # 1. 检测 SIFT 特征
    sift = cv2.SIFT_create()
    kp1, des1 = sift.detectAndCompute(img1, None)
    kp2, des2 = sift.detectAndCompute(img2, None)
    
    # 2. 特征匹配
    bf = cv2.BFMatcher()
    matches = bf.knnMatch(des1, des2, k=2)
    
    # 3. Lowe's ratio test
    good = []
    for match_pair in matches:
        if len(match_pair) == 2:
            m, n = match_pair
            if m.distance < 0.75 * n.distance:
                good.append(m)
    
    # 4. 获取对应点
    src_pts = np.float32([kp1[m.queryIdx].pt for m in good]).reshape(-1, 1, 2)
    dst_pts = np.float32([kp2[m.trainIdx].pt for m in good]).reshape(-1, 1, 2)
    
    # 5. 计算单应矩阵
    M, mask = cv2.findHomography(src_pts, dst_pts, cv2.RANSAC, 5.0)
    
    # 6. 应用变换
    aligned = cv2.warpPerspective(img1, M, 
                                  (img2.shape[1], img2.shape[0]))
    
    return aligned, M
```

## 4. 性能优化与实践

### 4.1 高效的缩放管道

```python
class ScalingPipeline:
    """多尺度缩放优化"""
    
    @staticmethod
    def downscale_efficiently(img, target_size):
        """通过逐步缩放降低计算复杂度"""
        h, w = img.shape[:2]
        th, tw = target_size
        
        # 如果缩放比例很大，逐步缩放
        scale = min(w / tw, h / th)
        
        if scale > 2.0:
            # 逐步缩放：每次缩放到一半
            while scale > 2.0:
                h, w = int(h * 0.5), int(w * 0.5)
                img = cv2.resize(img, (w, h))
                scale = min(w / tw, h / th)
        
        # 最后一次精确缩放
        img = cv2.resize(img, target_size, 
                        interpolation=cv2.INTER_LINEAR)
        return img
    
    @staticmethod
    def upscale_with_super_resolution(img, scale=2):
        """使用超分辨率技术的上采样"""
        # OpenCV 4.4+ 支持多种超分辨率模型
        sr = cv2.dnn_superres.DnnSuperResImpl_create()
        sr.readModel('ESPCN_x2.pb')
        sr.setModel('espcn', scale)
        result = sr.upsample(img)
        return result
```

### 4.2 批量变换优化

```python
# 对多张图像应用相同变换
def batch_transform(images, M, output_size):
    """批量应用变换矩阵"""
    results = []
    for img in images:
        result = cv2.warpAffine(img, M, output_size)
        results.append(result)
    return np.array(results)

# 使用 NumPy 向量化
def vectorized_transform(images, angles):
    """向量化旋转"""
    results = []
    for img, angle in zip(images, angles):
        M = cv2.getRotationMatrix2D(
            (img.shape[1]//2, img.shape[0]//2), angle, 1.0)
        result = cv2.warpAffine(img, M, 
                               (img.shape[1], img.shape[0]))
        results.append(result)
    return np.array(results)
```

## 5. 应用案例

### 5.1 自动图像拼接（Image Stitching）

```python
def stitch_images(img1, img2):
    """将两张重叠的图像拼接"""
    
    # 1. 特征检测与匹配（见配准章节）
    sift = cv2.SIFT_create()
    kp1, des1 = sift.detectAndCompute(img1, None)
    kp2, des2 = sift.detectAndCompute(img2, None)
    
    bf = cv2.BFMatcher()
    matches = bf.knnMatch(des1, des2, k=2)
    
    good = []
    for match_pair in matches:
        if len(match_pair) == 2:
            m, n = match_pair
            if m.distance < 0.75 * n.distance:
                good.append(m)
    
    # 2. 计算单应矩阵
    src_pts = np.float32([kp1[m.queryIdx].pt for m in good]).reshape(-1, 1, 2)
    dst_pts = np.float32([kp2[m.trainIdx].pt for m in good]).reshape(-1, 1, 2)
    
    H, mask = cv2.findHomography(src_pts, dst_pts, cv2.RANSAC, 5.0)
    
    # 3. 计算输出尺寸
    h1, w1 = img1.shape[:2]
    h2, w2 = img2.shape[:2]
    
    # 计算 img1 变换后的四个角点
    corners = np.float32([[0, 0], [w1, 0], [w1, h1], [0, h1]]).reshape(-1, 1, 2)
    transformed_corners = cv2.perspectiveTransform(corners, H)
    
    all_corners = np.concatenate([
        np.float32([[0, 0], [w2, 0], [w2, h2], [0, h2]]).reshape(-1, 1, 2),
        transformed_corners
    ])
    
    x_min = int(np.min(all_corners[:, 0, 0]))
    y_min = int(np.min(all_corners[:, 0, 1]))
    x_max = int(np.max(all_corners[:, 0, 0]))
    y_max = int(np.max(all_corners[:, 0, 1]))
    
    output_width = x_max - x_min
    output_height = y_max - y_min
    
    # 4. 调整单应矩阵以适应新坐标系
    offset = np.array([[1, 0, -x_min],
                       [0, 1, -y_min],
                       [0, 0, 1]])
    H_adjusted = offset @ H
    
    # 5. 创建输出图像
    result = np.zeros((output_height, output_width, 3), dtype=np.uint8)
    
    # 放置 img2
    result[-y_min:-y_min+h2, -x_min:-x_min+w2] = img2
    
    # 放置 img1（变换后）
    warped = cv2.warpPerspective(img1, H_adjusted, 
                                (output_width, output_height))
    
    # 混合重叠区域
    mask = warped > 0
    result[mask] = cv2.addWeighted(result[mask], 0.5, warped[mask], 0.5, 0)
    
    return result
```

### 5.2 OCR 预处理

```python
def preprocess_for_ocr(img):
    """为 OCR 进行图像变换与增强"""
    
    # 1. 检测文档
    gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
    blurred = cv2.GaussianBlur(gray, (5, 5), 0)
    edges = cv2.Canny(blurred, 50, 150)
    
    # 2. 检测轮廓
    contours, _ = cv2.findContours(edges, cv2.RETR_EXTERNAL, 
                                     cv2.CHAIN_APPROX_SIMPLE)
    
    if not contours:
        return img
    
    # 3. 找最大矩形
    largest = max(contours, key=cv2.contourArea)
    peri = cv2.arcLength(largest, True)
    approx = cv2.approxPolyDP(largest, 0.02 * peri, True)
    
    if len(approx) == 4:
        # 4. 透视变换
        pts = approx.reshape(4, 2)
        rect = order_points(pts)
        
        widthA = np.sqrt((rect[3][0] - rect[2][0])**2 + 
                         (rect[3][1] - rect[2][1])**2)
        widthB = np.sqrt((rect[1][0] - rect[0][0])**2 + 
                         (rect[1][1] - rect[0][1])**2)
        width = max(int(widthA), int(widthB))
        
        heightA = np.sqrt((rect[1][0] - rect[2][0])**2 + 
                          (rect[1][1] - rect[2][1])**2)
        heightB = np.sqrt((rect[0][0] - rect[3][0])**2 + 
                          (rect[0][1] - rect[3][1])**2)
        height = max(int(heightA), int(heightB))
        
        dst = np.array([[0, 0], [width, 0], [width, height], [0, height]],
                      dtype=np.float32)
        M = cv2.getPerspectiveTransform(rect, dst)
        warped = cv2.warpPerspective(img, M, (width, height))
        
        # 5. 增强对比度
        gray = cv2.cvtColor(warped, cv2.COLOR_BGR2GRAY)
        clahe = cv2.createCLAHE(clipLimit=2.0, tileGridSize=(8, 8))
        enhanced = clahe.apply(gray)
        
        return enhanced
    
    return img
```

## 6. 常见问题

**Q1: 旋转后出现黑色区域怎么办？**  
A: 使用 `cv2.BORDER_REFLECT` 或 `cv2.BORDER_REPLICATE` 填充；或者计算新的输出大小以包含所有内容。

**Q2: 仿射 vs 透视变换何时使用？**  
A: 仿射保持平行性（用于平面旋转、倾斜）；透视用于 3D 视角变换（文档扫描、建筑物）。

**Q3: 大幅度缩小图像后质量下降？**  
A: 使用逐步缩放或超分辨率；或使用 `cv2.INTER_AREA` 进行下采样。

**Q4: 变换矩阵如何求逆？**  
A: 使用 `M_inv = cv2.invertAffineTransform(M)` 或 `np.linalg.inv(M_3x3)`。
