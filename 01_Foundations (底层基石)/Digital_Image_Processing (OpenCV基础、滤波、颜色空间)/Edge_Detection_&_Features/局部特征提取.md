# 🎯 局部特征提取详解

## 概述

局部特征（Local Features）是图像中具有**独特性和可重复性**的点或区域。用于：
- 图像匹配和对齐
- 物体识别
- SLAM 和三维重建
- 图像检索

## 1. 特征点的性质

### 1.1 好的特征点应有

| 特性 | 说明 |
|------|------|
| **可重复性** | 同一物体的不同图像中能重复检测到 |
| **独特性** | 与周围点明显不同，易于匹配 |
| **局部性** | 不受全局变化影响 |
| **稳定性** | 对光照、尺度、旋转等变化鲁棒 |
| **计算效率** | 检测速度快 |

### 1.2 特征点的类型

```
特征点类型
├─ 角点（Corner）      → Harris, FAST
├─ 斑点（Blob）        → DoG, LoG
├─ 边缘点（Edge）      → 边界上的特殊点
└─ 纹理点（Texture）   → 纹理丰富的区域
```

## 2. Harris 角点检测

### 2.1 原理

Harris 检测角点的思想：**不同方向的梯度变化都很大**的点是角点。

对于像素 $(x, y)$ 周围的小窗口，如果在**所有方向**上都有大的强度变化，则该点是角点。

自相关矩阵：
$$M = \begin{bmatrix} I_x^2 & I_x I_y \\ I_x I_y & I_y^2 \end{bmatrix}$$

其中 $I_x, I_y$ 是梯度。通过对 $M$ 的特征值分析：
- $\lambda_1, \lambda_2$ 都很大 → **角点**（两个方向都有变化）
- $\lambda_1 >> \lambda_2$ → **边缘**（一个方向有变化）
- $\lambda_1, \lambda_2$ 都很小 → **平坦区域**（无明显变化）

Harris 响应函数：
$$R = \det(M) - k \cdot \text{trace}(M)^2 = \lambda_1 \lambda_2 - k(\lambda_1 + \lambda_2)^2$$

其中 $k$ 通常取 0.04～0.06。

### 2.2 OpenCV 实现

```python
import cv2
import numpy as np

# 基本用法
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)

# Harris 角点检测
corners = cv2.cornerHarris(gray, blockSize=2, ksize=3, k=0.04)

# 阈值化提取角点
threshold = 0.01 * corners.max()
corner_coords = np.where(corners > threshold)

# 绘制角点
result = img.copy()
for y, x in zip(corner_coords[0], corner_coords[1]):
    cv2.circle(result, (x, y), 5, (0, 255, 0), -1)
```

### 2.3 完整流程

```python
def harris_corner_detection(img, block_size=2, k_size=3, k=0.04):
    """完整的 Harris 角点检测"""
    
    # 1. 转灰度
    gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
    
    # 2. Harris 检测
    harris = cv2.cornerHarris(gray, blockSize=block_size, ksize=k_size, k=k)
    
    # 3. 非极大值抑制
    harris_norm = cv2.normalize(harris, None, 0, 255, cv2.NORM_MINMAX, cv2.CV_32F)
    
    # 4. 局部最大值
    threshold = 0.01 * harris_norm.max()
    corners = np.where(harris_norm > threshold)
    
    # 5. 亚像素精度
    corners_refined = cv2.cornerSubPix(
        gray, np.float32(np.column_stack(corners[::-1])),
        (5, 5), (-1, -1),
        criteria=(cv2.TERM_CRITERIA_EPS + cv2.TERM_CRITERIA_MAX_ITER, 100, 0.001))
    
    return harris, corners_refined
```

```python
    while True:
        block_size = cv2.getTrackbarPos('Block Size', 'Harris Detection') * 2 + 1
        k = cv2.getTrackbarPos('K', 'Harris Detection') / 100.0
        threshold_pct = cv2.getTrackbarPos('Threshold %', 'Harris Detection') / 100.0
        
        harris = cv2.cornerHarris(gray, block_size, 3, k)
        
        result = img.copy()

            cv2.circle(result, (x, y), 3, (0, 255, 0), -1)
        
        cv2.imshow('Harris Detection', result)
        
        if cv2.waitKey(1) & 0xFF == ord('q'):
            break
    
    cv2.destroyAllWindows()
```

## 3. SIFT（尺度不变特征变换）

### 3.1 原理

SIFT 是最著名的局部特征描述符之一，具有：
- ✅ 尺度不变性（多尺度金字塔）
- ✅ 旋转不变性（梯度方向直方图）
- ✅ 光照不变性（梯度基）
- ✅ 高度可区分性（128 维描述符）
- ❌ 计算复杂度高
- ❌ 专利限制（已过期）

### 3.2 主要步骤

#### 步骤 1：构建尺度空间（Scale Space）

使用高斯金字塔和高斯差分金字塔（DoG）：

$$L(x, y, \sigma) = G(x, y, \sigma) * I(x, y)$$
$$D(x, y, \sigma) = L(x, y, k\sigma) - L(x, y, \sigma)$$

#### 步骤 2：特征点检测

在 DoG 中找**局部极值**（与 26 个邻域比较）。

#### 步骤 3：特征点定位与过滤

- 亚像素精度定位
- 移除低对比度点
- 移除边缘响应

#### 步骤 4：方向分配

计算特征点邻域的梯度直方图，取主方向。

#### 步骤 5：描述符生成

在 16×16 邻域内计算 128 维梯度直方图描述符。

### 3.3 OpenCV 实现

```python
# SIFT 特征检测与描述
sift = cv2.SIFT_create()

# 检测关键点和描述符
keypoints, descriptors = sift.detectAndCompute(gray, None)

# 绘制关键点
result = cv2.drawKeypoints(img, keypoints, None)

# 检测细节
def analyze_sift_features(img):
    """分析 SIFT 特征"""
    gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
    sift = cv2.SIFT_create()
    
    keypoints, descriptors = sift.detectAndCompute(gray, None)
    
    print(f"检测到 {len(keypoints)} 个关键点")
    print(f"描述符维度: {descriptors.shape}")
    
    # 按响应强度排序
    responses = [kp.response for kp in keypoints]
    sorted_idx = np.argsort(responses)[::-1]
    
    top_keypoints = [keypoints[i] for i in sorted_idx[:20]]
    
    result = cv2.drawKeypoints(img, top_keypoints, None,
                               flags=cv2.DRAW_MATCHES_FLAGS_DRAW_RICH_KEYPOINTS)
    
    return result, keypoints, descriptors
```

### 3.4 SIFT 特征匹配

```python
def match_sift_features(img1, img2):
    """SIFT 特征匹配"""
    
    gray1 = cv2.cvtColor(img1, cv2.COLOR_BGR2GRAY)
    gray2 = cv2.cvtColor(img2, cv2.COLOR_BGR2GRAY)
    
    sift = cv2.SIFT_create()
    
    # 检测特征
    kp1, des1 = sift.detectAndCompute(gray1, None)
    kp2, des2 = sift.detectAndCompute(gray2, None)
    
    # 特征匹配 - BFMatcher
    bf = cv2.BFMatcher()
    matches = bf.knnMatch(des1, des2, k=2)
    
    # Lowe's ratio test
    good_matches = []
    for match_pair in matches:
        if len(match_pair) == 2:
            m, n = match_pair
            if m.distance < 0.75 * n.distance:
                good_matches.append(m)
    
    # 绘制匹配结果
    result = cv2.drawMatches(img1, kp1, img2, kp2, good_matches,
                            None, flags=cv2.DrawMatchesFlags_NOT_DRAW_SINGLE_POINTS)
    
    return result, good_matches, kp1, kp2
```

## 4. ORB（Oriented FAST and Rotated BRIEF）

### 4.1 原理

ORB 是一个**免专利、高速**的特征描述符：
- ✅ 速度快（比 SIFT 快几百倍）
- ✅ 无专利限制
- ✅ 旋转不变
- ❌ 描述性能不如 SIFT
- ❌ 对尺度变化不够鲁棒

### 4.2 实现

```python
# ORB 特征检测
orb = cv2.ORB_create(nfeatures=500)

keypoints, descriptors = orb.detectAndCompute(gray, None)

# 特征匹配
def match_orb_features(img1, img2):
    """ORB 特征匹配"""
    
    gray1 = cv2.cvtColor(img1, cv2.COLOR_BGR2GRAY)
    gray2 = cv2.cvtColor(img2, cv2.COLOR_BGR2GRAY)
    
    orb = cv2.ORB_create(nfeatures=1000)
    
    kp1, des1 = orb.detectAndCompute(gray1, None)
    kp2, des2 = orb.detectAndCompute(gray2, None)
    
    # 使用 Hamming 距离
    bf = cv2.BFMatcher(cv2.NORM_HAMMING, crossCheck=True)
    matches = bf.match(des1, des2)
    matches = sorted(matches, key=lambda x: x.distance)
    
    # 绘制最好的匹配
    result = cv2.drawMatches(img1, kp1, img2, kp2, matches[:20],
                            None)
    
    return result, matches[:20]
```

### 5.2 选择建议

```
应用场景 → 推荐特征

实时应用（SLAM、AR）      → ORB, FAST+BRIEF
精确匹配（图像检索）       → SIFT, SURF
鲁棒性（尺度+旋转变化）   → SIFT, AKAZE, BRISK
资源受限（移动端）         → ORB, BRIEF
```

## 6. 实际应用

### 6.1 图像拼接

```python
def stitch_images_with_features(img1, img2):
    """使用特征匹配进行图像拼接"""
    
    # 特征检测与匹配
    sift = cv2.SIFT_create()
    
    kp1, des1 = sift.detectAndCompute(img1, None)
    kp2, des2 = sift.detectAndCompute(img2, None)
    
    bf = cv2.BFMatcher()
    matches = bf.knnMatch(des1, des2, k=2)
    
    # Lowe's ratio test
    good = []
    for match_pair in matches:
        if len(match_pair) == 2:
            m, n = match_pair
            if m.distance < 0.75 * n.distance:
                good.append(m)
    
    # 计算单应矩阵
    src_pts = np.float32([kp1[m.queryIdx].pt for m in good]).reshape(-1, 1, 2)
    dst_pts = np.float32([kp2[m.trainIdx].pt for m in good]).reshape(-1, 1, 2)
    
    H, mask = cv2.findHomography(src_pts, dst_pts, cv2.RANSAC, 5.0)
    
    # 配准和拼接
    result = cv2.warpPerspective(img1, H, 
                                (img1.shape[1] + img2.shape[1], img1.shape[0]))
    result[0:img2.shape[0], img1.shape[1]:] = img2
    
    return result
```

### 6.2 物体追踪

```python
def track_object_with_features(video_path, frame_idx=0):
    """使用特征匹配追踪物体"""
    
    cap = cv2.VideoCapture(video_path)
    
    # 读取第一帧作为模板
    ret, template = cap.read()
    if not ret:
        return None
    
    sift = cv2.SIFT_create()
    bf = cv2.BFMatcher()
    
    kp_template, des_template = sift.detectAndCompute(template, None)
    
    frame_count = 0
    while True:
        ret, frame = cap.read()
        if not ret:
            break
        
        # 特征匹配
        kp_frame, des_frame = sift.detectAndCompute(frame, None)
        matches = bf.knnMatch(des_template, des_frame, k=2)
        
        # Lowe's ratio test
        good = []
        for match_pair in matches:
            if len(match_pair) == 2:
                m, n = match_pair
                if m.distance < 0.75 * n.distance:
                    good.append(m)
        
        # 如果匹配足够好
        if len(good) > 10:
            src_pts = np.float32([kp_template[m.queryIdx].pt for m in good]).reshape(-1, 1, 2)
            dst_pts = np.float32([kp_frame[m.trainIdx].pt for m in good]).reshape(-1, 1, 2)
            
            H, mask = cv2.findHomography(src_pts, dst_pts, cv2.RANSAC, 5.0)
            
            if H is not None:
                # 绘制边界框
                h, w = template.shape[:2]
                corners = np.float32([[0, 0], [w, 0], [w, h], [0, h]]).reshape(-1, 1, 2)
                transformed = cv2.perspectiveTransform(corners, H)
                
                frame = cv2.polylines(frame, [np.int32(transformed)], True, (0, 255, 0), 2)
        
        cv2.imshow('Object Tracking', frame)
        if cv2.waitKey(1) & 0xFF == ord('q'):
            break
        
        frame_count += 1
    
    cap.release()
    cv2.destroyAllWindows()
```

### 6.3 场景识别

```python
def recognize_scene_from_features(query_img, reference_images):
    """使用特征进行场景识别"""
    
    sift = cv2.SIFT_create()
    bf = cv2.BFMatcher()
    
    # 提取查询图像特征
    kp_query, des_query = sift.detectAndCompute(query_img, None)
    
    best_match = None
    max_good_matches = 0
    
    # 与每个参考图像比较
    for ref_img in reference_images:
        kp_ref, des_ref = sift.detectAndCompute(ref_img, None)
        
        matches = bf.knnMatch(des_query, des_ref, k=2)
        
        good = []
        for match_pair in matches:
            if len(match_pair) == 2:
                m, n = match_pair
                if m.distance < 0.75 * n.distance:
                    good.append(m)
        
        if len(good) > max_good_matches:
            max_good_matches = len(good)
            best_match = ref_img
    
    print(f"最佳匹配：{max_good_matches} 个好匹配")
    
    return best_match
```

## 7. 性能优化

```python
def optimize_feature_extraction():
    """特征提取优化技巧"""
    
    # 1. 使用 mask 限制特征检测区域
    mask = np.zeros(img.shape[:2], dtype=np.uint8)
    mask[100:400, 100:400] = 255  # 只在感兴趣区域检测
    
    sift = cv2.SIFT_create()
    kp, des = sift.detectAndCompute(img, mask)
    
    # 2. 限制特征数量
    orb = cv2.ORB_create(nfeatures=500)  # 最多 500 个特征
    
    # 3. 多线程特征提取
    from concurrent.futures import ThreadPoolExecutor
    
    def extract_features_parallel(images):
        with ThreadPoolExecutor(max_workers=4) as executor:
            results = list(executor.map(
                lambda x: sift.detectAndCompute(x, None), images))
        return results
```
