# 图像表示与颜色空间

## 概述
图像的本质是二维数组，但如何表示颜色信息至关重要。不同的颜色空间适合不同的应用场景。

## 基本概念

### 1. 数字图像的定义
- **离散化**：连续空间 → 网格采样（像素）
- **量化**：连续亮度 → 离散灰度值（通常 0-255）
- **维度**：灰度图(H×W)，彩色图(H×W×3)

### 2. 图像坐标系
- **Origin 在左上角**：(0,0)
- **x 轴向右**，**y 轴向下**
- **在 Python 中**：`img[y, x]` 或 `img[row, col]`

### 3. 像素深度（Bit Depth）
- **uint8**：0-255（最常见）
- **uint16**：0-65535（医学影像）
- **float32**：0.0-1.0（深度学习）

## RGB 颜色空间

### 基本原理
- **三原色**：红(R)、绿(G)、蓝(B)
- **加色混合**：R+G+B=白色
- **人眼类型**：三种锥细胞对应三原色

### RGB 值范围
```python
import numpy as np

# uint8 编码（常见）
R, G, B = 255, 128, 0  # 橙色
img = np.array([[[B, G, R]]], dtype=np.uint8)  # OpenCV 中为 BGR

# float32 编码（深度学习）
img_float = img.astype(np.float32) / 255.0
```

### 在 OpenCV 中的顺序
**OpenCV 使用 BGR 而非 RGB！**
```python
import cv2

# 读取图像为 BGR
img = cv2.imread('image.jpg')  # BGR 格式

# 转换为 RGB
img_rgb = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)

# 转换为灰度
img_gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
```

### 应用场景
- **显示器**：RGB 原理
- **摄像头**：Bayer 阵列 → 插值得到 RGB
- **网页/深度学习**：通常用 RGB

## HSV 颜色空间

### 三个分量
- **H (Hue)**：色调 (0-180° 在 OpenCV 中)
  - 红：0°，绿：60°，蓝：120°
  - 色彩循环特性
  
- **S (Saturation)**：饱和度 (0-255)
  - 0：灰色（无色彩）
  - 255：纯色
  
- **V (Value)**：明度 (0-255)
  - 0：黑色
  - 255：最亮

### 几何表示
```
       顶点：白色
      /   \
    红     黄
    |       |
    品红    绿
      \   /
      底部：黑色
```

### 优势
1. **颜色分割容易**：只需指定色调范围
2. **光照不变性**：分离了颜色和亮度
3. **人类直观**：对应日常颜色描述

### 代码示例
```python
import cv2
import numpy as np

# 读取图像
img = cv2.imread('image.jpg')

# 转换为 HSV
hsv = cv2.cvtColor(img, cv2.COLOR_BGR2HSV)
H, S, V = cv2.split(hsv)

# 提取红色（两个范围）
lower_red1 = np.array([0, 100, 100])
upper_red1 = np.array([10, 255, 255])
lower_red2 = np.array([170, 100, 100])
upper_red2 = np.array([180, 255, 255])

mask1 = cv2.inRange(hsv, lower_red1, upper_red1)
mask2 = cv2.inRange(hsv, lower_red2, upper_red2)
red_mask = cv2.bitwise_or(mask1, mask2)

# 应用掩码
result = cv2.bitwise_and(img, img, mask=red_mask)
```

### 应用
- [[../Pixel_Operations_&_Transformation|颜色分割]]
- 肤色检测（医学、美颜应用）
- 颜色直方图匹配

## 其他颜色空间

### YUV / YCbCr 颜色空间
- **Y**：亮度（灰度值）
- **U/Cb**：色度（蓝色差异）
- **V/Cr**：色度（红色差异）

**优势**：
- 分离亮度和色度
- JPEG 压缩使用 YCbCr
- 视频编码标准

**转换关系**：
```python
# RGB to YCbCr
img_ycbcr = cv2.cvtColor(img_rgb, cv2.COLOR_RGB2YCrCb)

# 应用：人脸检测、JPEG 压缩
```

### LAB 颜色空间
- **L**：亮度 (0-100)
- **a**：绿-红轴 (-127-127)
- **b**：蓝-黄轴 (-127-127)

**特点**：
- 接近人眼感知
- **均匀色空间**：距离对应感知差异
- 与设备无关

**应用**：
```python
# 颜色聚类（K-Means）中更好的距离度量
img_lab = cv2.cvtColor(img_rgb, cv2.COLOR_RGB2LAB)
```

### 灰度空间
将彩色转换为灰度：

**加权平均**（NTSC 标准）：
$$Gray = 0.299 \cdot R + 0.587 \cdot G + 0.114 \cdot B$$

**简单平均**：
$$Gray = \frac{R + G + B}{3}$$

**最大值法**：
$$Gray = \max(R, G, B)$$

```python
# OpenCV
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)

# 手动实现
gray = 0.299*img[:,:,2] + 0.587*img[:,:,1] + 0.114*img[:,:,0]
```

## 颜色空间转换矩阵

### RGB ↔ YUV
$$\begin{bmatrix} Y \\ U \\ V \end{bmatrix} = \begin{bmatrix} 0.299 & 0.587 & 0.114 \\ -0.147 & -0.289 & 0.436 \\ 0.615 & -0.515 & -0.100 \end{bmatrix} \begin{bmatrix} R \\ G \\ B \end{bmatrix}$$

## Bayer 阵列与图像采集

### 相机的工作过程
```
光线 → Bayer 滤波阵列 → 采集 → 插值 → RGB 图像
            GRGR...
            BGBG...
```

### Bayer 图案
```
R G R G R
G B G B G
R G R G R
G B G B G
```

特点：
- 绿色像素最多（2/4），对应人眼敏感性
- 红、蓝各占 1/4

### 去马赛克（Demosaicing）
从 Bayer 阵列恢复完整 RGB：

**最近邻插值**：简单但质量差
**双线性插值**：效果较好
**高级算法**：自适应滤波、边界感知

```python
# 在 OpenCV 中：
# 相机直接输出通常已经是 RGB 或 BGR
# 如果得到 Bayer 格式，使用：
img_bgr = cv2.cvtColor(bayer_img, cv2.COLOR_BayerRG2BGR)
```

## 练习题

1. 手动计算灰度转换：给定 RGB(255,128,0)，计算灰度值
2. 编写函数转换 RGB ↔ HSV
```python
import cv2
import numpy as np

# 1. 创建一个随机的 BGR 颜色点 (也可以加载图片: cv2.imread('path.jpg'))
# 注意：OpenCV 默认是 BGR 顺序，不是 RGB
color_bgr = np.uint8([[[51, 87, 255]]]) 

# 2. BGR 转换为 HSV
color_hsv = cv2.cvtColor(color_bgr, cv2.COLOR_BGR2HSV)

# 3. HSV 转换为 BGR
color_bgr_back = cv2.cvtColor(color_hsv, cv2.COLOR_HSV2BGR)

print(f"BGR 原始值: {color_bgr}")
print(f"HSV 转换值: {color_hsv}")
print(f"还原后的 BGR: {color_bgr_back}")

```
1. 从 Bayer 阵列恢复 RGB（实现双线性插值）
2. 比较不同颜色空间下的颜色分割效果
