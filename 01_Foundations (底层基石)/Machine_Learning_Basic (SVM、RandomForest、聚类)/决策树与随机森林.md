# 决策树与随机森林

决策树通过一系列“如果某个特征小于某个阈值”的规则划分样本。随机森林由多棵决策树组成，通过投票或平均降低单棵树的过拟合。

## 决策树直觉

决策树类似一组嵌套规则：

```text
if edge_density < 0.12:
    class = background
else:
    if texture_score > 0.45:
        class = defect
    else:
        class = normal
```

树模型的核心是：每次选择一个特征和阈值，让划分后的节点更“纯”。

## 划分标准

### Gini impurity

$$
Gini=1-\sum_k p_k^2
$$

如果一个节点中全是同一类，Gini 为 0。

### Entropy

$$
Entropy=-\sum_k p_k\log p_k
$$

信息增益：

$$
Gain=Entropy(parent)-\sum_j\frac{n_j}{n}Entropy(child_j)
$$

## 决策树参数

| 参数 | 作用 |
|------|------|
| `max_depth` | 限制树深度，防止过拟合 |
| `min_samples_split` | 节点至少多少样本才继续分裂 |
| `min_samples_leaf` | 叶子节点至少保留多少样本 |
| `criterion` | `gini` 或 `entropy` |

## 随机森林

随机森林的两个随机性：

1. 样本随机：每棵树用 bootstrap 样本训练。
2. 特征随机：每次分裂只看部分特征。

最终：

- 分类任务：多数投票。
- 回归任务：多棵树预测平均。

## 示例代码：决策树分类

```python
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier, export_text
from sklearn.metrics import classification_report

X, y = make_classification(
    n_samples=300,
    n_features=6,
    n_informative=4,
    random_state=0,
)

feature_names = [f"feature_{i}" for i in range(X.shape[1])]

X_train, X_val, y_train, y_val = train_test_split(
    X, y, test_size=0.25, stratify=y, random_state=0
)

tree = DecisionTreeClassifier(
    max_depth=4,
    min_samples_leaf=5,
    random_state=0,
)

tree.fit(X_train, y_train)
pred = tree.predict(X_val)

print(classification_report(y_val, pred))
print(export_text(tree, feature_names=feature_names))
```

## 示例代码：随机森林分类与特征重要性

```python
import numpy as np
from sklearn.datasets import make_classification
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import train_test_split
from sklearn.metrics import classification_report

X, y = make_classification(
    n_samples=600,
    n_features=10,
    n_informative=4,
    n_redundant=2,
    random_state=0,
)

feature_names = np.array([f"feature_{i}" for i in range(X.shape[1])])

X_train, X_val, y_train, y_val = train_test_split(
    X, y, test_size=0.25, stratify=y, random_state=0
)

forest = RandomForestClassifier(
    n_estimators=200,
    max_depth=8,
    min_samples_leaf=3,
    random_state=0,
    n_jobs=-1,
)

forest.fit(X_train, y_train)
pred = forest.predict(X_val)

print(classification_report(y_val, pred))

order = np.argsort(forest.feature_importances_)[::-1]
for idx in order[:5]:
    print(feature_names[idx], forest.feature_importances_[idx])
```

## 示例代码：图像统计特征 + 随机森林

```python
import cv2
import numpy as np
from pathlib import Path
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import train_test_split
from sklearn.metrics import classification_report

def image_features(path):
    image = cv2.imread(str(path), cv2.IMREAD_GRAYSCALE)
    image = cv2.resize(image, (128, 128))

    mean = image.mean()
    std = image.std()
    lap_var = cv2.Laplacian(image, cv2.CV_64F).var()
    edges = cv2.Canny(image, 80, 160)
    edge_ratio = (edges > 0).mean()

    hist = cv2.calcHist([image], [0], None, [16], [0, 256]).ravel()
    hist = hist / max(hist.sum(), 1)

    return np.r_[mean, std, lap_var, edge_ratio, hist]

paths = []
labels = []
for class_id, class_name in enumerate(["normal", "defect"]):
    for path in Path("data").joinpath(class_name).glob("*.jpg"):
        paths.append(path)
        labels.append(class_id)

X = np.array([image_features(path) for path in paths])
y = np.array(labels)

X_train, X_val, y_train, y_val = train_test_split(
    X, y, test_size=0.2, stratify=y, random_state=0
)

model = RandomForestClassifier(n_estimators=150, random_state=0)
model.fit(X_train, y_train)

pred = model.predict(X_val)
print(classification_report(y_val, pred, target_names=["normal", "defect"]))
```

## 示例代码：随机森林回归

```python
from sklearn.datasets import make_regression
from sklearn.ensemble import RandomForestRegressor
from sklearn.model_selection import train_test_split
from sklearn.metrics import mean_absolute_error, r2_score

X, y = make_regression(
    n_samples=500,
    n_features=8,
    n_informative=5,
    noise=10.0,
    random_state=0,
)

X_train, X_val, y_train, y_val = train_test_split(
    X, y, test_size=0.25, random_state=0
)

model = RandomForestRegressor(
    n_estimators=200,
    max_depth=10,
    min_samples_leaf=2,
    random_state=0,
    n_jobs=-1,
)

model.fit(X_train, y_train)
pred = model.predict(X_val)

print("mae:", mean_absolute_error(y_val, pred))
print("r2:", r2_score(y_val, pred))
```

## 优缺点

决策树优点：

- 可解释，能打印规则。
- 不需要特征标准化。
- 能处理非线性特征交互。

决策树缺点：

- 单棵树容易过拟合。
- 对数据扰动敏感。

随机森林优点：

- 比单棵树稳。
- 对特征尺度不敏感。
- 可以输出特征重要性。
- 小数据和表格特征上很强。

随机森林缺点：

- 模型体积较大。
- 推理速度比单棵树慢。
- 不适合直接处理原始高分辨率图像。

## 与 CV 的连接

树模型适合处理已经提取好的特征：

```text
图像
  ↓
颜色直方图 / 纹理 / 边缘比例 / 几何统计量 / 深度特征
  ↓
决策树或随机森林
  ↓
分类、回归、特征重要性分析
```

常见用途：

- 缺陷检测 baseline。
- 图像质量评分。
- 小数据分类。
- 分析哪些统计特征最有用。
