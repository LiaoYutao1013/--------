# 启发式学习

启发式学习不是一个单一模型，而是一类“用经验规则或搜索策略寻找较好解”的方法。它常用于目标函数不可导、搜索空间巨大、精确求解成本太高的问题。

在机器学习和 CV 工程中，启发式方法经常用于：

- 阈值选择。
- 特征选择。
- 超参数搜索。
- 数据增强策略搜索。
- anchor 设计。
- 后处理规则调优。

## 与梯度学习的区别

| 方法 | 依赖梯度 | 适用对象 |
|------|----------|----------|
| 梯度下降 | 是 | 可导损失函数、神经网络、线性模型 |
| 网格搜索 | 否 | 小规模离散超参数 |
| 随机搜索 | 否 | 参数范围较大时的快速探索 |
| 贪心搜索 | 否 | 每一步选择当前最优 |
| 遗传算法 | 否 | 组合优化、策略搜索 |
| 模拟退火 | 否 | 容易陷入局部最优的问题 |

## 网格搜索

网格搜索枚举所有参数组合，适合搜索空间较小的情况。

示例：搜索 SVM 的 `C` 和 `gamma`。

```python
from sklearn.datasets import make_classification
from sklearn.model_selection import GridSearchCV, train_test_split
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.svm import SVC

X, y = make_classification(
    n_samples=500,
    n_features=10,
    n_informative=5,
    random_state=0,
)

X_train, X_val, y_train, y_val = train_test_split(
    X, y, test_size=0.25, stratify=y, random_state=0
)

pipe = Pipeline([
    ("scaler", StandardScaler()),
    ("svm", SVC()),
])

param_grid = {
    "svm__C": [0.1, 1, 10],
    "svm__gamma": [0.01, 0.1, 1],
    "svm__kernel": ["rbf"],
}

search = GridSearchCV(pipe, param_grid, scoring="f1", cv=5)
search.fit(X_train, y_train)

print("best params:", search.best_params_)
print("cv f1:", search.best_score_)
print("val f1:", search.score(X_val, y_val))
```

## 随机搜索

随机搜索从参数空间中随机采样。参数较多时，它常比网格搜索更高效。

```python
from scipy.stats import loguniform
from sklearn.datasets import make_classification
from sklearn.model_selection import RandomizedSearchCV
from sklearn.svm import SVC

X, y = make_classification(n_samples=600, n_features=20, random_state=0)

param_dist = {
    "C": loguniform(1e-2, 1e2),
    "gamma": loguniform(1e-3, 1e1),
    "kernel": ["rbf"],
}

search = RandomizedSearchCV(
    SVC(),
    param_distributions=param_dist,
    n_iter=30,
    scoring="accuracy",
    cv=5,
    random_state=0,
)

search.fit(X, y)
print(search.best_params_)
print(search.best_score_)
```

## 贪心特征选择

贪心策略每一步加入当前最能提升验证分数的特征。

```python
import numpy as np
from sklearn.datasets import make_classification
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import f1_score
from sklearn.model_selection import train_test_split

X, y = make_classification(
    n_samples=400,
    n_features=12,
    n_informative=4,
    random_state=0,
)

X_train, X_val, y_train, y_val = train_test_split(
    X, y, test_size=0.25, stratify=y, random_state=0
)

selected = []
remaining = list(range(X.shape[1]))

for step in range(4):
    best_feature = None
    best_score = -1

    for feature in remaining:
        candidate = selected + [feature]
        model = LogisticRegression(max_iter=1000)
        model.fit(X_train[:, candidate], y_train)
        pred = model.predict(X_val[:, candidate])
        score = f1_score(y_val, pred)

        if score > best_score:
            best_score = score
            best_feature = feature

    selected.append(best_feature)
    remaining.remove(best_feature)
    print("step:", step + 1, "selected:", selected, "f1:", best_score)
```

## 阈值搜索

很多视觉系统最终需要选择阈值：

- 分类置信度阈值。
- 边缘检测阈值。
- NMS IoU 阈值。
- 分割 mask 阈值。

示例：根据验证集选择最佳分类阈值。

```python
import numpy as np
from sklearn.metrics import f1_score

y_true = np.array([0, 0, 1, 1, 1, 0, 1, 0])
scores = np.array([0.10, 0.35, 0.42, 0.60, 0.90, 0.55, 0.72, 0.20])

best = None
for threshold in np.linspace(0.1, 0.9, 17):
    pred = (scores >= threshold).astype(int)
    f1 = f1_score(y_true, pred)
    if best is None or f1 > best["f1"]:
        best = {"threshold": threshold, "f1": f1}

print(best)
```

## 遗传算法直觉

遗传算法把一个候选解看成“个体”，通过选择、交叉、变异不断产生新解。

适合：

- 特征子集选择。
- 数据增强策略搜索。
- 后处理规则组合。

最小示例：搜索二值特征开关。

```python
import random

def score(mask):
    # 假设第 0、2、5 个特征有用，特征太多会有惩罚
    useful = sum(mask[i] for i in [0, 2, 5])
    penalty = 0.15 * sum(mask)
    return useful - penalty

rng = random.Random(0)
population = [
    [rng.randint(0, 1) for _ in range(8)]
    for _ in range(20)
]

for generation in range(30):
    population = sorted(population, key=score, reverse=True)
    parents = population[:6]

    children = []
    while len(children) < 14:
        a, b = rng.sample(parents, 2)
        cut = rng.randint(1, 7)
        child = a[:cut] + b[cut:]

        # mutation
        if rng.random() < 0.25:
            idx = rng.randrange(len(child))
            child[idx] = 1 - child[idx]

        children.append(child)

    population = parents + children

best = max(population, key=score)
print("best mask:", best)
print("score:", score(best))
```

## 模拟退火直觉

模拟退火允许搜索过程偶尔接受更差的解，从而跳出局部最优。

```python
import math
import random

def objective(x):
    return -(x - 2) ** 2 + math.sin(5 * x)

rng = random.Random(0)
x = rng.uniform(-5, 5)
temperature = 1.0

for step in range(200):
    candidate = x + rng.uniform(-0.5, 0.5)
    delta = objective(candidate) - objective(x)

    if delta > 0 or rng.random() < math.exp(delta / temperature):
        x = candidate

    temperature *= 0.97

print("best x:", x)
print("objective:", objective(x))
```

## 在 CV 中的用法

启发式学习通常不替代模型训练，而是补充工程搜索：

```text
训练模型
  ↓
验证集预测
  ↓
搜索阈值、NMS、增强、特征组合
  ↓
选择最优配置
  ↓
测试集最终评估
```

注意：所有搜索都应只在训练集或验证集上进行，不能根据测试集反复调整。
