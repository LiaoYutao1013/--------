# 无监督学习

无监督学习没有人工标签，目标是从数据本身发现结构。

```text
只有 x，没有 y
  ↓
聚类、降维、异常发现、表示学习
```

在 CV 中，无监督学习常用于图像探索、颜色聚类、特征可视化、anchor 聚类和异常样本发现。

## 常见任务

| 任务 | 输出 | 例子 |
|------|------|------|
| 聚类 | 样本所属簇 | 图像分组、颜色分割、anchor 聚类 |
| 降维 | 低维表示 | 特征可视化、压缩 |
| 异常检测 | 异常分数 | 缺陷发现、脏数据清洗 |
| 密度估计 | 数据分布 | outlier detection |

## K-Means

K-Means 假设数据可以被划分为 $K$ 个簇，每个样本属于最近的中心。

目标函数：

$$
\min \sum_i \|x_i-\mu_{c_i}\|^2
$$

流程：

```text
随机初始化 K 个中心
  ↓
把每个样本分配到最近中心
  ↓
重新计算每个簇中心
  ↓
重复直到中心稳定
```

## 示例代码：K-Means 颜色聚类

```python
import cv2
import numpy as np
from sklearn.cluster import KMeans

image = cv2.imread("image.jpg")
image_rgb = cv2.cvtColor(image, cv2.COLOR_BGR2RGB)

pixels = image_rgb.reshape(-1, 3)

kmeans = KMeans(n_clusters=5, random_state=0, n_init="auto")
kmeans.fit(pixels)

centers = kmeans.cluster_centers_.astype(np.uint8)
labels = kmeans.labels_

quantized = centers[labels].reshape(image_rgb.shape)
quantized_bgr = cv2.cvtColor(quantized, cv2.COLOR_RGB2BGR)

cv2.imwrite("color_clustered.jpg", quantized_bgr)
print("cluster centers:", centers)
```

## 示例代码：YOLO anchor 尺寸聚类

```python
import numpy as np
from sklearn.cluster import KMeans

# 每行是一个标注框宽高，已经归一化到 0~1
boxes_wh = np.array([
    [0.04, 0.06],
    [0.05, 0.08],
    [0.12, 0.10],
    [0.18, 0.22],
    [0.30, 0.28],
    [0.45, 0.40],
])

kmeans = KMeans(n_clusters=3, random_state=0, n_init="auto")
kmeans.fit(boxes_wh)

anchors = kmeans.cluster_centers_
anchors = anchors[np.argsort(anchors.prod(axis=1))]

print("anchors:")
for w, h in anchors:
    print(f"{w:.3f}, {h:.3f}")
```

## DBSCAN

DBSCAN 基于密度，不需要预先指定簇数。

关键参数：

- `eps`：邻域半径。
- `min_samples`：形成核心点所需的最少邻居数。

特点：

- 能发现任意形状簇。
- 能识别噪声点。
- 对参数尺度敏感，通常需要标准化。

## 示例代码：DBSCAN 异常发现

```python
from sklearn.datasets import make_blobs
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import DBSCAN
import numpy as np

X, _ = make_blobs(
    n_samples=300,
    centers=3,
    cluster_std=0.55,
    random_state=0,
)

# 加入异常点
outliers = np.array([[5, 5], [-5, 4], [4, -4]])
X = np.vstack([X, outliers])

X_scaled = StandardScaler().fit_transform(X)

dbscan = DBSCAN(eps=0.35, min_samples=5)
labels = dbscan.fit_predict(X_scaled)

print("cluster labels:", sorted(set(labels)))
print("outlier count:", (labels == -1).sum())
```

## PCA

PCA 是线性降维方法，寻找数据方差最大的方向。

流程：

```text
中心化数据
  ↓
计算协方差矩阵
  ↓
特征值分解或 SVD
  ↓
选择前 k 个主成分
```

## 示例代码：PCA 可视化高维特征

```python
from sklearn.datasets import load_digits
from sklearn.decomposition import PCA
from sklearn.preprocessing import StandardScaler

digits = load_digits()
X = digits.data
y = digits.target

X_scaled = StandardScaler().fit_transform(X)

pca = PCA(n_components=2, random_state=0)
X_2d = pca.fit_transform(X_scaled)

print("2d feature shape:", X_2d.shape)
print("explained variance ratio:", pca.explained_variance_ratio_)

# 可继续用 matplotlib 按 y 上色画散点图
```

## 聚类评价

无监督学习没有真实标签时，评价更困难。

常见指标：

| 指标 | 是否需要标签 | 解释 |
|------|--------------|------|
| inertia | 否 | K-Means 簇内平方和，越小越紧 |
| silhouette | 否 | 簇内近、簇间远时更高 |
| ARI | 是 | 聚类结果与真实标签的一致性 |
| NMI | 是 | 归一化互信息 |

## 示例代码：选择 K 值

```python
from sklearn.datasets import make_blobs
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score

X, _ = make_blobs(n_samples=500, centers=4, random_state=0)

for k in range(2, 8):
    model = KMeans(n_clusters=k, random_state=0, n_init="auto")
    labels = model.fit_predict(X)
    score = silhouette_score(X, labels)
    print(k, score)
```

## 与 CV 的连接

- 颜色聚类：将图像颜色压缩成少数主色。
- 图像检索：用聚类构建视觉词袋。
- 目标检测：用 K-Means 聚类 anchor 尺寸。
- 特征分析：用 PCA/t-SNE/UMAP 看深度特征是否按类别分开。
- 数据清洗：用 DBSCAN 找异常样本。
