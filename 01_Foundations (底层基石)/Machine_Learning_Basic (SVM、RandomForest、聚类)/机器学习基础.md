# 机器学习基础

机器学习基础用于连接传统视觉方法和深度学习方法。很多 CV 问题在深度学习出现前已经有成熟的特征工程、分类器、聚类、降维和评价体系。

这份笔记作为本目录索引，具体知识点拆到子节点中展开。

```text
任务类型
  ↓
有监督学习 / 无监督学习
  ↓
线性模型、SVM、决策树、聚类、降维
  ↓
训练流程、评价指标、调参方法
  ↓
在视觉任务中构建 baseline 或分析工具
```

## 机器学习问题分类

### 有监督学习

训练数据包含输入和标签：

```text
(x, y) -> 学习 f(x) ≈ y
```

常见任务：

- 回归：输出连续值，例如预测目标框坐标、深度、关键点坐标。
- 分类：输出类别，例如猫狗分类、缺陷类型分类。
- 排序：输出相对顺序，例如检索系统中的相似度排序。

入口：[[有监督学习]]

### 无监督学习

训练数据只有输入，没有人工标签：

```text
x -> 发现聚类、低维结构、异常样本或表示空间
```

常见任务：

- 聚类：K-Means、DBSCAN、层次聚类。
- 降维：PCA、t-SNE、UMAP。
- 密度估计与异常检测。

入口：[[无监督学习]]

## 常见模型地图

```text
线性模型
  ├── 多元线性回归：连续值预测
  ├── 岭回归 / Lasso：带正则的线性回归
  └── 逻辑回归：分类概率

间隔模型
  └── SVM：最大间隔分类，可配合核函数

树模型
  ├── 决策树：规则划分
  ├── 随机森林：bagging 集成
  └── GBDT / XGBoost：boosting 集成

无监督模型
  ├── K-Means：中心聚类
  ├── DBSCAN：密度聚类
  └── PCA：线性降维

搜索类方法
  ├── 贪心搜索
  ├── 遗传算法
  ├── 模拟退火
  └── 网格 / 随机超参搜索
```

## 与计算机视觉的关系

传统 CV 经常采用如下流程：

```text
图像
  ↓
人工特征：HOG / SIFT / LBP / 颜色直方图
  ↓
机器学习模型：SVM / 随机森林 / K-Means
  ↓
分类、检测、聚类或检索
```

深度学习出现后，很多人工特征被 CNN/Transformer 自动学习的特征替代，但传统机器学习仍然重要：

- 小数据集上可作为快速 baseline。
- 表格特征、统计特征和工程特征常比端到端深度模型更稳。
- PCA、聚类、KNN、SVM 常用于分析深度特征。
- 决策树和随机森林适合解释特征重要性。
- 启发式搜索常用于阈值、超参和数据策略选择。

## 最小实践顺序

1. 用 [[线性模型（多元线性回归）]] 做一个回归 baseline。
2. 用 [[有监督学习]] 训练一个分类器，记录 Accuracy、Precision、Recall、F1。
3. 用 [[SVM 支持向量机]] 在二维数据或 HOG 特征上做最大间隔分类。
4. 用 [[决策树与随机森林]] 比较树模型和线性模型的可解释性。
5. 用 [[无监督学习]] 做颜色聚类、特征聚类或 anchor 聚类。
6. 用 [[启发式学习]] 搜索阈值、特征子集或超参数。
