# 有监督学习

有监督学习指训练数据中同时包含输入 $x$ 和目标标签 $y$，模型学习一个映射：

$$
f(x)\approx y
$$

在视觉任务中，$x$ 通常来自图像、图像块、目标框、人工特征或深度特征；$y$ 可以是类别、坐标、分数或 mask。

## 任务类型

| 类型 | 输出 | 视觉例子 |
|------|------|----------|
| 分类 | 离散类别 | 猫狗分类、缺陷类型识别 |
| 回归 | 连续数值 | 目标框坐标、关键点坐标、深度估计 |
| 多标签分类 | 多个二值标签 | 一张图同时含有车、人、交通灯 |
| 序列预测 | 序列标签 | 视频动作识别、OCR |

## 标准训练流程

```text
收集数据
  ↓
标注标签
  ↓
划分 train / val / test
  ↓
特征提取或模型设计
  ↓
训练
  ↓
验证集调参
  ↓
测试集报告最终性能
  ↓
错误分析
```

## 训练集、验证集、测试集

- 训练集：用于更新模型参数。
- 验证集：用于调超参数、选择模型。
- 测试集：只在最后评估一次，估计真实泛化性能。

不要用测试集反复调参，否则测试结果会变成“间接训练结果”。

## 分类指标

| 指标 | 解释 |
|------|------|
| Accuracy | 所有样本中预测正确的比例 |
| Precision | 预测为正的样本中有多少是真的 |
| Recall | 真实为正的样本中有多少被找回 |
| F1 | Precision 和 Recall 的调和平均 |
| Confusion Matrix | 展示每个类别被预测成什么 |

## 回归指标

| 指标 | 解释 |
|------|------|
| MSE | 均方误差 |
| MAE | 平均绝对误差 |
| RMSE | 均方根误差 |
| $R^2$ | 解释方差比例 |

## 示例代码：训练一个分类器

```python
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import Pipeline
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import accuracy_score, classification_report, confusion_matrix

X, y = make_classification(
    n_samples=500,
    n_features=8,
    n_informative=4,
    n_redundant=2,
    random_state=0,
)

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.25, stratify=y, random_state=0
)

model = Pipeline([
    ("scaler", StandardScaler()),
    ("clf", LogisticRegression(max_iter=1000)),
])

model.fit(X_train, y_train)
pred = model.predict(X_test)

print("accuracy:", accuracy_score(y_test, pred))
print(confusion_matrix(y_test, pred))
print(classification_report(y_test, pred))
```

## 示例代码：训练一个回归器

```python
from sklearn.datasets import make_regression
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestRegressor
from sklearn.metrics import mean_absolute_error, mean_squared_error, r2_score

X, y = make_regression(
    n_samples=400,
    n_features=6,
    n_informative=4,
    noise=12.0,
    random_state=0,
)

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.25, random_state=0
)

model = RandomForestRegressor(
    n_estimators=100,
    max_depth=8,
    random_state=0,
)

model.fit(X_train, y_train)
pred = model.predict(X_test)

print("mae:", mean_absolute_error(y_test, pred))
print("mse:", mean_squared_error(y_test, pred))
print("r2:", r2_score(y_test, pred))
```

## 示例代码：用图像统计特征做缺陷分类 baseline

```python
import cv2
import numpy as np
from pathlib import Path
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import classification_report

def extract_features(image_path):
    image = cv2.imread(str(image_path), cv2.IMREAD_GRAYSCALE)
    if image is None:
        raise ValueError(f"cannot read image: {image_path}")

    mean = image.mean()
    std = image.std()
    edges = cv2.Canny(image, 80, 160)
    edge_ratio = (edges > 0).mean()
    hist = cv2.calcHist([image], [0], None, [8], [0, 256]).ravel()
    hist = hist / max(hist.sum(), 1)
    return np.r_[mean, std, edge_ratio, hist]

# 假设目录结构：
# data/ok/*.jpg
# data/defect/*.jpg
paths = []
labels = []
for label_name, label in [("ok", 0), ("defect", 1)]:
    for path in Path("data").joinpath(label_name).glob("*.jpg"):
        paths.append(path)
        labels.append(label)

X = np.array([extract_features(path) for path in paths])
y = np.array(labels)

X_train, X_val, y_train, y_val = train_test_split(
    X, y, test_size=0.2, stratify=y, random_state=0
)

model = RandomForestClassifier(n_estimators=100, random_state=0)
model.fit(X_train, y_train)

pred = model.predict(X_val)
print(classification_report(y_val, pred, target_names=["ok", "defect"]))
```

## 常见风险

### 数据泄漏

同一张图的增强版本、同一视频的相邻帧、同一病人的多张图像不能随意分到 train 和 test，否则评估会虚高。

### 类别不均衡

缺陷检测、医学图像中正负样本常严重不均衡。可以尝试：

- 分层采样：`stratify=y`
- 类别权重：`class_weight="balanced"`
- 过采样少数类
- 使用 Precision、Recall、F1，而不是只看 Accuracy

### 验证集过拟合

如果反复根据验证集调参，验证集也会被“用旧”。最终仍需要独立测试集。

## 与深度学习的关系

深度学习本质上仍属于有监督学习的一大类。区别在于：

- 传统 ML 通常先人工提取特征，再训练分类器。
- 深度学习把特征提取和分类器一起训练。
- 小数据、表格特征、工程特征场景下，传统 ML 依然非常实用。
