# 线性模型（多元线性回归）

线性模型假设输出可以由输入特征的线性组合表示：

$$
\hat{y}=w_1x_1+w_2x_2+\cdots+w_dx_d+b
$$

其中：

- $x$ 是输入特征。
- $w$ 是每个特征的权重。
- $b$ 是偏置。
- $\hat{y}$ 是模型预测。

## 多元线性回归

多元线性回归用于预测连续值。它与一元线性回归的区别是输入不再只有一个特征，而是多个特征。

例如在视觉任务中，可以用一些图像统计特征预测连续目标：

- 根据图像亮度、对比度、纹理强度预测清晰度评分。
- 根据目标框宽高、面积、长宽比预测检测置信度。
- 根据相机参数和图像坐标估计几何量。

## 矩阵形式

对 $n$ 个样本、$d$ 个特征：

$$
X\in \mathbb{R}^{n\times d},\quad y\in \mathbb{R}^{n}
$$

线性预测为：

$$
\hat{y}=Xw+b
$$

常把偏置合并进特征矩阵：

$$
\tilde{X}=[X, \mathbf{1}],\quad \theta=[w,b]
$$

于是：

$$
\hat{y}=\tilde{X}\theta
$$

## 损失函数

最常见的是均方误差：

$$
MSE=\frac{1}{n}\sum_{i=1}^{n}(\hat{y}_i-y_i)^2
$$

训练目标：

$$
\min_{w,b}\frac{1}{n}\|Xw+b-y\|^2
$$

## 求解方式

### 正规方程

如果数据量不大，可以直接求闭式解：

$$
\theta=(X^TX)^{-1}X^Ty
$$

实际实现通常不用显式求逆，而使用 `np.linalg.lstsq` 或 `np.linalg.solve`，数值更稳定。

### 梯度下降

当样本较多或模型更复杂时，可用梯度下降：

```text
初始化 w, b
重复：
  计算预测 y_hat
  计算误差 y_hat - y
  计算梯度
  更新 w, b
```

## 正则化

线性模型容易受异常值、多重共线性和噪声影响。常见正则化：

| 方法 | 目标 | 直觉 |
|------|------|------|
| Ridge | MSE + $\lambda\|w\|_2^2$ | 让权重更小、更平滑 |
| Lasso | MSE + $\lambda\|w\|_1$ | 让部分权重变成 0，做特征选择 |
| Elastic Net | L1 + L2 | 同时兼顾稀疏与稳定 |

## 示例代码：NumPy 求解多元线性回归

```python
import numpy as np

# 4 个样本，3 个特征：亮度、对比度、纹理强度
X = np.array([
    [0.20, 0.80, 0.30],
    [0.40, 0.60, 0.50],
    [0.70, 0.30, 0.90],
    [0.90, 0.20, 0.70],
], dtype=float)

# 连续标签：例如人工标注的图像质量分数
y = np.array([0.42, 0.55, 0.78, 0.82], dtype=float)

# 拼接一列 1，用于学习偏置 b
X_aug = np.c_[X, np.ones(len(X))]

# 最小二乘解，比直接求逆更稳定
theta, *_ = np.linalg.lstsq(X_aug, y, rcond=None)
w = theta[:-1]
b = theta[-1]

pred = X @ w + b
mse = np.mean((pred - y) ** 2)

print("weights:", w)
print("bias:", b)
print("prediction:", pred)
print("mse:", mse)
```

## 示例代码：梯度下降训练

```python
import numpy as np

rng = np.random.default_rng(0)
X = rng.normal(size=(200, 3))
true_w = np.array([1.5, -2.0, 0.7])
true_b = 0.3
y = X @ true_w + true_b + rng.normal(scale=0.2, size=200)

w = np.zeros(3)
b = 0.0
lr = 0.05

for epoch in range(200):
    pred = X @ w + b
    error = pred - y

    grad_w = (2 / len(X)) * X.T @ error
    grad_b = 2 * error.mean()

    w -= lr * grad_w
    b -= lr * grad_b

    if epoch % 50 == 0:
        mse = np.mean(error ** 2)
        print(epoch, mse)

print("learned w:", w)
print("learned b:", b)
```

## 示例代码：scikit-learn 版本

```python
import numpy as np
from sklearn.linear_model import LinearRegression, Ridge, Lasso
from sklearn.model_selection import train_test_split
from sklearn.metrics import mean_squared_error, r2_score

rng = np.random.default_rng(42)
X = rng.normal(size=(300, 5))
y = 1.2 * X[:, 0] - 0.7 * X[:, 2] + 0.3 * X[:, 4] + rng.normal(scale=0.1, size=300)

X_train, X_val, y_train, y_val = train_test_split(X, y, test_size=0.25, random_state=0)

models = {
    "linear": LinearRegression(),
    "ridge": Ridge(alpha=1.0),
    "lasso": Lasso(alpha=0.01),
}

for name, model in models.items():
    model.fit(X_train, y_train)
    pred = model.predict(X_val)
    print(name)
    print("  mse:", mean_squared_error(y_val, pred))
    print("  r2:", r2_score(y_val, pred))
    print("  coef:", model.coef_)
```

## 评价指标

| 指标 | 含义 |
|------|------|
| MSE | 平方误差均值，对大误差更敏感 |
| MAE | 绝对误差均值，更直观 |
| RMSE | MSE 开根号，与原标签单位一致 |
| $R^2$ | 模型解释方差的比例，越接近 1 越好 |

## 常见问题

### 特征尺度差异很大

线性模型和正则化模型通常需要标准化：

```python
from sklearn.preprocessing import StandardScaler

scaler = StandardScaler()
X_train_scaled = scaler.fit_transform(X_train)
X_val_scaled = scaler.transform(X_val)
```

### 特征强相关

如果特征之间强相关，普通线性回归的权重可能不稳定。可优先尝试 Ridge。

### 关系明显非线性

线性模型本身只能拟合线性关系，但可以通过构造特征扩展能力：

- 多项式特征：$x^2, xy, x^3$
- 统计特征：均值、方差、纹理强度
- 深度特征：CNN backbone 输出后接线性回归

## 与 CV 的连接

- 图像质量评价：用亮度、噪声、边缘强度预测质量分数。
- 目标检测分析：用目标面积、长宽比预测检测误差或置信度。
- 相机标定：很多几何问题会先转化为线性最小二乘。
- 深度学习：最后一层全连接分类头本质上也是线性模型。
