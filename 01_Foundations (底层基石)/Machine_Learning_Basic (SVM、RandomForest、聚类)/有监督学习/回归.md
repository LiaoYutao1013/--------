# 回归

回归是有监督学习中预测连续数值的任务。训练数据由输入 $x$ 和连续目标 $y$ 组成，模型学习：

$$
f(x) \rightarrow y,\quad y \in \mathbb{R}^d
$$

当 $d=1$ 时是单输出回归，例如预测一个分数；当 $d>1$ 时是多输出回归，例如同时预测目标框的四个坐标或人体关键点的多个坐标。

在计算机视觉中，回归非常常见：

- 目标检测中的边界框坐标：$(x, y, w, h)$
- 关键点检测中的坐标：$(x_1,y_1,\dots,x_n,y_n)$
- 深度估计中的像素深度值
- 相机标定中的参数估计
- 图像质量评分、尺寸测量、角度估计

## 回归和分类的区别

| 对比项 | 分类 | 回归 |
|--------|------|------|
| 输出 | 离散类别 | 连续数值 |
| 例子 | 缺陷类型 | 缺陷长度 |
| 常用损失 | 交叉熵、hinge loss | MSE、MAE、Huber |
| 常用指标 | Accuracy、F1、AUC | MAE、RMSE、$R^2$ |
| 预测解释 | 属于哪个类别 | 数值偏差有多大 |

如果目标本质上有顺序但只有少量等级，例如 `轻微 / 中等 / 严重`，可以建成分类问题；如果等级间距有明确数值含义，也可以建成回归问题。建模方式取决于业务需要什么输出。

## 标签形式

### 单输出回归

每个样本对应一个数值：

```text
图像 -> 亮度评分
图像 -> 物体实际宽度
特征 -> 缺陷长度
```

标签形状通常是：

```text
y.shape = (n_samples,)
```

### 多输出回归

每个样本对应多个连续数值：

```text
目标候选框 -> [x_min, y_min, x_max, y_max]
人脸图像 -> [left_eye_x, left_eye_y, right_eye_x, right_eye_y, ...]
```

标签形状通常是：

```text
y.shape = (n_samples, n_outputs)
```

多输出回归中，不同输出量纲可能不同。比如坐标是像素，角度是度，置信分数是 0 到 1。训练前需要确认是否要归一化目标值。

## 常见模型

| 模型 | 特点 | 适合场景 |
|------|------|----------|
| Linear Regression | 简单、可解释，拟合线性关系 | 快速 baseline、特征与目标近似线性 |
| Ridge / Lasso | 带正则化的线性回归 | 特征多、共线性强、需要控制过拟合 |
| SVR | 支持非线性核函数 | 中小规模数据、特征质量较好 |
| Decision Tree Regressor | 分段常数拟合，可解释 | 非线性关系、规则分析 |
| Random Forest Regressor | 多棵树平均，稳定性较好 | 表格特征、统计特征、非线性 baseline |
| Gradient Boosting / XGBoost | 强预测能力 | 结构化数据、竞赛和工业 baseline |
| Neural Network | 表达能力强 | 图像到坐标、深度、关键点等端到端任务 |

## 损失函数

### MSE

均方误差：

$$
MSE=\frac{1}{n}\sum_{i=1}^{n}(y_i-\hat{y}_i)^2
$$

MSE 会放大大误差，对离群点敏感。它适合希望强烈惩罚大偏差的场景。

### MAE

平均绝对误差：

$$
MAE=\frac{1}{n}\sum_{i=1}^{n}|y_i-\hat{y}_i|
$$

MAE 更接近“平均差多少”的直觉，对离群点比 MSE 稳健。

### RMSE

均方根误差：

$$
RMSE=\sqrt{MSE}
$$

RMSE 和原始目标值单位一致，便于解释。例如目标单位是毫米，RMSE 也是毫米。

### Huber Loss

Huber Loss 在误差小时类似 MSE，误差大时类似 MAE：

$$
L_\delta(a)=
\begin{cases}
\frac{1}{2}a^2, & |a|\le\delta \\
\delta(|a|-\frac{1}{2}\delta), & |a|>\delta
\end{cases}
$$

它适合存在少量离群点，但又希望模型在普通样本上保持平滑优化的场景。

### Quantile Loss

分位数损失用于预测区间或分位点。例如预测“90% 情况下不会超过的误差上界”。在风险评估、测量不确定性建模中有用。

## 评价指标

| 指标 | 含义 | 注意点 |
|------|------|--------|
| MAE | 平均绝对误差 | 直观，单位与目标一致 |
| MSE | 平均平方误差 | 对大误差敏感 |
| RMSE | MSE 开方 | 单位与目标一致，仍偏重较大误差 |
| $R^2$ | 解释方差比例 | 可能为负，不能单独代表业务误差 |
| MAPE | 平均相对百分比误差 | 目标接近 0 时不稳定 |

$R^2$ 的定义为：

$$
R^2=1-\frac{\sum_i(y_i-\hat{y}_i)^2}{\sum_i(y_i-\bar{y})^2}
$$

$R^2=1$ 表示完美拟合；$R^2=0$ 表示和总是预测均值差不多；$R^2<0$ 表示还不如简单预测均值。

视觉测量任务里，最终指标最好换算成业务单位。例如“平均误差 2.3 像素”可能不直观，可以进一步换成毫米、角度或相对误差。

## 数据预处理

### 输入特征缩放

线性模型、SVR、KNN、神经网络通常对特征尺度敏感，建议标准化：

```text
x_scaled = (x - mean) / std
```

树模型和随机森林对单调缩放不敏感，通常不强制要求标准化。

### 目标值缩放

如果目标值范围很大，神经网络训练可能不稳定。可以对 $y$ 做标准化，预测后再反变换。

```text
y_scaled = (y - y_mean) / y_std
```

坐标回归中常把像素坐标归一化到 0 到 1：

```text
x_norm = x_pixel / image_width
y_norm = y_pixel / image_height
```

这样模型不会强依赖某一个固定分辨率。

### 离群点检查

回归对异常标签非常敏感。训练前应检查：

- 标签单位是否一致。
- 是否有明显不可能的数值。
- 坐标是否超出图像范围。
- 缺失值是否被错误填成 0。
- 标注工具导出的坐标顺序是否一致。

## 视觉任务中的回归例子

### 目标框回归

目标检测模型通常同时做分类和回归：

```text
候选区域 -> 类别
候选区域 -> 目标框偏移量
```

直接回归绝对坐标并不总是最优，实际检测器常预测相对 anchor 或候选框的偏移量：

$$
t_x=\frac{x-x_a}{w_a},\quad t_y=\frac{y-y_a}{h_a}
$$

这样可以让目标值分布更稳定。

### 关键点回归

关键点任务可以直接回归坐标，也可以预测 heatmap。直接坐标回归简单，但空间细节可能不足；heatmap 方法更常用于人体姿态、人脸关键点等任务。

### 深度估计

单目深度估计可以看作每个像素都要预测一个连续值。它是密集回归任务，评价时常使用 MAE、RMSE、相对误差等指标。

## 示例代码：RandomForestRegressor

```python
from sklearn.datasets import make_regression
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestRegressor
from sklearn.metrics import mean_absolute_error, mean_squared_error, r2_score

X, y = make_regression(
    n_samples=600,
    n_features=8,
    n_informative=5,
    noise=12.0,
    random_state=0,
)

X_train, X_test, y_train, y_test = train_test_split(
    X,
    y,
    test_size=0.25,
    random_state=0,
)

model = RandomForestRegressor(
    n_estimators=200,
    max_depth=10,
    min_samples_leaf=3,
    random_state=0,
)

model.fit(X_train, y_train)
pred = model.predict(X_test)

mse = mean_squared_error(y_test, pred)
print("MAE:", mean_absolute_error(y_test, pred))
print("RMSE:", mse ** 0.5)
print("R2:", r2_score(y_test, pred))
```

随机森林能处理非线性关系，也不要求输入特征标准化，适合作为表格特征和人工视觉特征的快速 baseline。

## 示例代码：多输出回归

```python
import numpy as np
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestRegressor
from sklearn.metrics import mean_absolute_error

rng = np.random.default_rng(0)
X = rng.normal(size=(500, 12))

# 假设 y 是两个点的坐标：[x1, y1, x2, y2]
y = np.column_stack([
    30 + 5 * X[:, 0] + rng.normal(scale=1.0, size=500),
    40 + 3 * X[:, 1] + rng.normal(scale=1.0, size=500),
    80 + 4 * X[:, 2] + rng.normal(scale=1.0, size=500),
    90 + 2 * X[:, 3] + rng.normal(scale=1.0, size=500),
])

X_train, X_test, y_train, y_test = train_test_split(
    X,
    y,
    test_size=0.25,
    random_state=0,
)

model = RandomForestRegressor(n_estimators=100, random_state=0)
model.fit(X_train, y_train)

pred = model.predict(X_test)
print("overall MAE:", mean_absolute_error(y_test, pred))
print("per-output MAE:", np.abs(y_test - pred).mean(axis=0))
```

多输出任务不要只看总体平均误差，还要看每个输出维度的误差。关键点任务中，某些点可能比其他点更难预测。

## 残差分析

残差是：

$$
r_i = y_i - \hat{y}_i
$$

回归任务训练后应检查残差：

- 残差是否整体偏正或偏负，说明模型有系统偏差。
- 大误差是否集中在某些输入范围。
- 误差是否随着目标值变大而变大。
- 是否存在少数异常样本主导了 MSE。
- 测试集误差是否远高于训练集误差，说明可能过拟合。

## 常见风险

### 把分类问题硬做成回归

如果标签只是类别编号，例如 `0=猫、1=狗、2=鸟`，这些数字没有连续含义，不应直接做回归。否则模型会错误地认为类别 0 和类别 1 比类别 0 和类别 2 更接近。

### 目标值尺度不合适

坐标、面积、角度、距离混在一个目标向量里时，数值范围大的目标会主导损失。应考虑归一化、分任务加权或分别训练。

### 外推能力弱

许多回归模型只擅长在训练数据覆盖范围内插值。测试样本超出训练范围时，预测可能明显不可靠。生产部署前应检查目标值范围是否覆盖真实场景。

### 只看平均误差

平均误差可能掩盖尾部风险。工业测量中，少量极大误差可能比平均误差更关键。可以同时报告 P90、P95、最大误差或超差率。
