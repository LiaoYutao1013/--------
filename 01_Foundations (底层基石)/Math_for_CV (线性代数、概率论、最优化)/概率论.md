# 概率论与统计

## 概述
概率论是机器学习的理论基础，贝叶斯方法、概率图模型、深度学习中的不确定性都基于概率论。

## 核心概念

### 1. 概率分布
- **离散分布**：伯努利分布、二项分布、泊松分布
- **连续分布**：正态分布、均匀分布、指数分布
- **应用**：[[../../02_Deep_Learning_Core (神经网络核心)/Training_Techniques|损失函数设计]]

### 2. 统计推断
- 参数估计：最大似然估计（MLE）、最大后验（MAP）
- 假设检验：置信区间、p 值
- **应用**：模型评估、不确定性量化

### 3. 贝叶斯方法
- 贝叶斯定理：$P(A|B) = \frac{P(B|A)P(A)}{P(B)}$
- 先验、似然、后验
- **应用**：贝叶斯分类、贝叶斯深度学习

## 重要分布

### 高斯分布（正态分布）
最重要的连续分布。

**一元高斯**：
$$N(x|\mu, \sigma^2) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)$$

**多元高斯**：
$$N(x|\mu, \Sigma) = \frac{1}{(2\pi)^{D/2}|\Sigma|^{1/2}} \exp\left(-\frac{1}{2}(x-\mu)^T\Sigma^{-1}(x-\mu)\right)$$

**应用**：
- 噪声建模
- [[../Image_Filtering_&_Enhancement|高斯滤波]]
- 神经网络初始化

### 伯努利分布与分类分布
- **伯努利**：二分类（0 或 1）
- **分类分布**：多分类
- **应用**：Softmax、交叉熵损失

### 指数分布族
- 性质：充分统计量、共轭性
- 包括：高斯、伯努利、分类、指数、Gamma、...
- **应用**：变分推断、概率图模型

## 参数估计

### 最大似然估计（MLE）
给定数据 $D = \{x_1, ..., x_N\}$，求使似然最大的参数 $\theta$：

$$\theta_{MLE} = \arg\max_\theta \prod_{i=1}^N p(x_i|\theta)$$

取对数：
$$\theta_{MLE} = \arg\max_\theta \sum_{i=1}^N \log p(x_i|\theta)$$

**例子**：高斯分布参数估计
- $\mu_{MLE} = \frac{1}{N}\sum_i x_i$（样本均值）
- $\sigma^2_{MLE} = \frac{1}{N}\sum_i(x_i - \mu)^2$（样本方差）

### 最大后验估计（MAP）
加入先验 $p(\theta)$：

$$\theta_{MAP} = \arg\max_\theta p(\theta|D) = \arg\max_\theta \frac{p(D|\theta)p(\theta)}{p(D)}$$

取对数（忽略常数项）：
$$\theta_{MAP} = \arg\max_\theta \left[\sum_{i=1}^N \log p(x_i|\theta) + \log p(\theta)\right]$$

**应用**：正则化（先验相当于惩罚项）

## 贝叶斯推断

### 贝叶斯定理
$$p(\theta|D) = \frac{p(D|\theta)p(\theta)}{p(D)}$$

- **先验** $p(\theta)$：数据前的信念
- **似然** $p(D|\theta)$：模型预测数据的能力
- **后验** $p(\theta|D)$：观察数据后的更新信念
- **证据** $p(D)$：边际似然

### 贝叶斯分类
对于新样本 $x$，预测其属于类别 $c_k$ 的概率：

$$p(c_k|x) = \frac{p(x|c_k)p(c_k)}{p(x)}$$

**朴素贝叶斯假设**：特征条件独立
$$p(x|c_k) = \prod_j p(x_j|c_k)$$

**应用**：垃圾邮件分类、文本分类

## 概率图模型

### 贝叶斯网络
- 有向图，表示条件依赖关系
- 链式法则：$p(x_1,...,x_n) = \prod_i p(x_i|Pa_i)$

### 马尔可夫随机场
- 无向图，基于团的因子分解
- **应用**：[[../../../03_Computer_Vision_Tasks (核心任务)/Object_Detection|图像分割、结构化预测]]

### 隐马尔可夫模型（HMM）
- 时间序列模型
- 状态转移、观测概率
- **应用**：[[../../../03_Computer_Vision_Tasks (核心任务)/Object_Detection/Kalman Filter|目标跟踪]]

## 蒙特卡洛方法

### 随机抽样
从复杂分布 $p(x)$ 中抽样：

$$\mathbb{E}[f(x)] = \int f(x)p(x)dx \approx \frac{1}{N}\sum_{i=1}^N f(x_i)$$

### 重要性抽样
从容易的分布 $q(x)$ 中抽样：

$$\mathbb{E}_p[f(x)] = \mathbb{E}_q\left[f(x)\frac{p(x)}{q(x)}\right]$$

### MCMC（Markov Chain Monte Carlo）
- Gibbs 抽样
- Metropolis-Hastings 算法
- **应用**：贝叶斯推断、生成模型

## 统计检验

### 假设检验
- **零假设** $H_0$：默认假设
- **备择假设** $H_1$：要验证的假设
- **p 值**：在 $H_0$ 下观测到极端值的概率

### 置信区间
参数 $\theta$ 的 $95\%$ 置信区间 $[a, b]$：

$$P(\theta \in [a,b]) = 0.95$$

不是说 $\theta$ 有 $95\%$ 概率在区间内，而是这个区间有 $95\%$ 的概率包含真实参数。
