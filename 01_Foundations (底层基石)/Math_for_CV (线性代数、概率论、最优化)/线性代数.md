# 线性代数基础

## 概述
线性代数是计算机视觉的数学基础，图像处理、特征提取、神经网络等所有内容都基于线性代数。

## 核心概念

### 1. 向量与矩阵
- **向量**：表示点、方向、特征
- **矩阵**：表示线性变换、图像、特征矩阵
- 见：[[#矩阵运算]]

### 2. 线性变换
- 几何变换：旋转、缩放、投影
- 特征值分解、SVD 分解
- 应用：[[../../01_Foundations (底层基石)/Digital_Image_Processing (OpenCV基础、滤波、颜色空间)/Pixel_Operations_&_Transformation|图像变换]]

### 3. 特征值与特征向量
- $Av = \lambda v$
- PCA 降维、协方差矩阵
- 应用：[[../../01_Foundations (底层基石)/Digital_Image_Processing (OpenCV基础、滤波、颜色空间)/Edge_Detection_&_Features|特征提取]]

## 矩阵运算

### 基本运算
| 运算 | 符号 | 说明 |
|------|------|------|
| 加法 | $A + B$ | 对应元素相加 |
| 乘法 | $A \cdot B$ | 矩阵乘法 |
| 转置 | $A^T$ | 行列互换 |
| 行列式 | $\det(A)$ | 体积缩放因子 |
| 逆矩阵 | $A^{-1}$ | 满足 $AA^{-1} = I$ |
| Hadamard 积 | $A \odot B$ | 元素级相乘 |

### 重要分解
1. **特征值分解（EVD）**
   $$A = Q\Lambda Q^{-1}$$
   其中 $\Lambda$ 为特征值矩阵

2. **奇异值分解（SVD）**
   $$A = U\Sigma V^T$$
   应用：[[#SVD 应用]]

3. **QR 分解**
   $$A = QR$$
   用于求解线性方程组

4. **Cholesky 分解**
   $$A = LL^T$$
   用于对称正定矩阵

## SVD 应用

### 在计算机视觉中的应用
1. **图像压缩**：只保留前 k 个奇异值
2. **视觉去噪**：去除小奇异值对应的噪声
3. **相机标定**：[[../../03_Computer_Vision_Tasks (核心任务)/3D_Vision (NeRF, 3DGS, 点云)/3D_Geometry_Foundations/Camera Calibration|相机参数求解]]
4. **目标检测**：特征矩阵分解

## 核心应用案例

### 案例 1：图像旋转
旋转矩阵：
$$R(\theta) = \begin{bmatrix} \cos\theta & -\sin\theta \\ \sin\theta & \cos\theta \end{bmatrix}$$

变换：$x' = R(\theta) \cdot x$

见：[[../Pixel_Operations_&_Transformation|图像变换]]

### 案例 2：PCA 降维
```python
# 数据矩阵 X: n_samples × n_features
# 计算协方差矩阵
Cov = (X - X.mean(axis=0)).T @ (X - X.mean(axis=0))
# 特征值分解
eigenvalues, eigenvectors = np.linalg.eig(Cov)
# 投影到前 k 个主成分
X_reduced = X @ eigenvectors[:, :k]
```

### 案例 3：对极几何
[[../../03_Computer_Vision_Tasks (核心任务)/3D_Vision (NeRF, 3DGS, 点云)/3D_Geometry_Foundations/Epipolar Geometry|对极几何基础关系]]：
$$p'^T F p = 0$$
其中 $F$ 为本质矩阵，可通过 SVD 求解

## 常用技巧

### 矩阵求导
- 链式法则：$(AB)' = A'B + AB'$
- 梯度计算：用于反向传播
- 见：[[../最优化|最优化理论]]

### 数值稳定性
- 避免矩阵求逆：使用 LU 分解或 SVD
- 条件数：反映数值稳定性
- 正则化：添加小项以提高稳定性
