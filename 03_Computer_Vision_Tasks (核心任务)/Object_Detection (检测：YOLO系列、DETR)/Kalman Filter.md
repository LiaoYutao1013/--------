## 📖 笔记：卡尔曼滤波 (Kalman Filter) 深度指南

### 1. 直觉理解：它到底在做什么？

想象你在追踪一辆车。你有两个信息来源：

1. **预测 (Predict)**：基于上一秒的位置和速度，你推测它现在应该在哪。但你的物理模型不完美（比如车可能轻微颠簸），有**过程噪声**。
    
2. **观测 (Update)**：你通过传感器（如 YOLO 检测框）看到了它在哪。但传感器也不完美（比如像素抖动），有**测量噪声**。
    

**卡尔曼滤波的精髓：** 它不是简单地相信其中一个，而是根据两者的**不确定性（方差）**进行加权平均。它是数学意义上的“最优估计”。

---

## 2. 数学基石：状态空间表达式

在卡尔曼滤波中，我们用**高斯分布**来描述状态。一个状态由**均值向量 $\mathbf{x}$**（最可能的位置）和**协方差矩阵 $\mathbf{P}$**（不确定性）组成。

### 系统模型变量定义

- $\mathbf{x}_k$：$k$时刻的状态向量（如位置、速度）。
    
- $\mathbf{F}$：状态转移矩阵（描述物理规律，如 $s = v \cdot t$）。
    
- $\mathbf{P}_k$：状态协方差矩阵（反映我们对当前预测的多没信心）。
    
- $\mathbf{Q}$：过程噪声协方差（环境干扰，如风吹、路颠）。
    
- $\mathbf{z}_k$：观测向量（传感器的直接读数）。
    
- $\mathbf{H}$：观测矩阵（将状态映射到观测空间）。
    
- $\mathbf{R}$：测量噪声协方差（传感器的精度极限）。
    

---

## 3. 卡尔曼滤波的五个黄金公式

卡尔曼滤波是一个不断循环的过程，分为 **“预测”** 和 **“更新”** 两步。

### 第一步：预测 (Prediction)

预测当前的物体状态和不确定性。

1. **状态预测**：
    
    $$\hat{\mathbf{x}}_{k|k-1} = \mathbf{F} \hat{\mathbf{x}}_{k-1|k-1} + \mathbf{B} \mathbf{u}_k$$
    
    _(基于物理规律预测新位置)_
    
2. **协方差预测**：
    
    $$\mathbf{P}_{k|k-1} = \mathbf{F} \mathbf{P}_{k-1|k-1} \mathbf{F}^T + \mathbf{Q}$$
    
    _(预测后，不确定性通常会变大，因为加入了过程噪声)_
    

### 第二步：更新 (Update)

利用观测值修正预测。

3. **计算卡尔曼增益 (Kalman Gain)**：

$$\mathbf{K}_k = \mathbf{P}_{k|k-1} \mathbf{H}^T (\mathbf{H} \mathbf{P}_{k|k-1} \mathbf{H}^T + \mathbf{R})^{-1}$$

_(这是核心：决定是更相信预测还是更相信观测)_

4. **更新状态估计**：

$$\hat{\mathbf{x}}_{k|k} = \hat{\mathbf{x}}_{k|k-1} + \mathbf{K}_k (\mathbf{z}_k - \mathbf{H} \hat{\mathbf{x}}_{k|k-1})$$

_(修正后的位置 = 预测位置 + 增益 $\times$ 误差)_

5. **更新协方差**：

$$\mathbf{P}_{k|k} = (\mathbf{I} - \mathbf{K}_k \mathbf{H}) \mathbf{P}_{k|k-1}$$

_(有了观测信息，不确定性会减小)_

---

## 4. 核心推导：卡尔曼增益 $K$ 是怎么来的？

这是很多教程跳过的地方。我们希望找到一个 $\mathbf{K}$，使得更新后的状态 $\hat{\mathbf{x}}_{k|k}$ 与真实状态 $\mathbf{x}_k$ 之间的**均方误差最小**。

### 推导步骤

1. **定义误差**：$\mathbf{e}_k = \mathbf{x}_k - \hat{\mathbf{x}}_{k|k}$。
    
2. **最小化目标**：最小化误差协方差矩阵 $\mathbf{P}_{k|k} = E[\mathbf{e}_k \mathbf{e}_k^T]$ 的迹（Trace）。
    
3. **展开公式**：将状态更新公式代入 $\mathbf{P}_{k|k}$ 中。
    
4. **求导**：对 $\mathbf{K}$ 求导，并令导数为 0：
    
    $$\frac{\partial tr(\mathbf{P}_{k|k})}{\partial \mathbf{K}_k} = -2(\mathbf{H} \mathbf{P}_{k|k-1})^T + 2\mathbf{K}_k(\mathbf{H} \mathbf{P}_{k|k-1} \mathbf{H}^T + \mathbf{R}) = 0$$
    
5. **解出 $\mathbf{K}$**：
    
    $$\mathbf{K}_k = \mathbf{P}_{k|k-1} \mathbf{H}^T (\mathbf{H} \mathbf{P}_{k|k-1} \mathbf{H}^T + \mathbf{R})^{-1}$$
    

**结论：**

- 当 **$\mathbf{R}$ (测量噪声) 趋于 0** 时，$\mathbf{K} \approx \mathbf{H}^{-1}$，模型完全相信观测值。
    
- 当 **$\mathbf{P}$ (预测不确定性) 趋于 0** 时，$\mathbf{K} \approx 0$，模型完全相信预测值。

## 5. 对比：KF vs EKF vs UKF

| **算法**          | **适用场景**     | **核心特点**                        |
| --------------- | ------------ | ------------------------------- |
| **卡尔曼滤波 (KF)**  | 线性系统 + 高斯噪声  | 最优估计，计算极快。                      |
| **扩展卡尔曼 (EKF)** | 非线性系统（如雷达转动） | 使用 **泰勒展开** 做局部线性化。             |
| **无迹卡尔曼 (UKF)** | 强非线性系统       | 使用 **Sigma 点** 采样，比 EKF 更准但慢一点。 |
