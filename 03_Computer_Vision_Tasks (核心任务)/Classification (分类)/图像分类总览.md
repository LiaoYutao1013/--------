# 图像分类总览

图像分类是最基础的视觉任务：给定一张图像，预测它属于哪个类别。它也是理解 backbone、预训练和迁移学习的入口。

## 基本流程

```text
Image
  ↓
Backbone
  ↓
Global Pooling
  ↓
Linear Classifier
  ↓
Class Probabilities
```

## 分类任务类型

| 类型 | 输出 | 示例 |
|------|------|------|
| 单标签分类 | 一个类别 | 猫/狗/车 |
| 多标签分类 | 多个类别 | 一张图同时有车、人、交通灯 |
| 细粒度分类 | 相似类别中的细分 | 鸟类品种、车型识别 |
| 长尾分类 | 类别样本极不均衡 | 工业缺陷、医学影像 |

## 常用模型

- CNN：ResNet、EfficientNet、MobileNet、ConvNeXt。
- Transformer：ViT、Swin Transformer。
- 轻量模型：MobileNetV3、ShuffleNet。

## 损失函数

单标签分类常用交叉熵：

$$L=-\sum_i y_i \log p_i$$

多标签分类常用二元交叉熵：

$$L=-\sum_i [y_i\log p_i + (1-y_i)\log(1-p_i)]$$

类别不平衡时可使用：
- class weight
- Focal Loss
- 重采样
- Label Smoothing

## 迁移学习

小数据集上通常不从零训练：

1. 加载 ImageNet 预训练 backbone。
2. 替换分类头。
3. 先冻结 backbone 训练分类头。
4. 再低学习率微调整个网络。

## 评价指标

- Accuracy：整体准确率。
- Top-k Accuracy：预测前 k 个类别中包含真值。
- Precision / Recall / F1：适合类别不平衡。
- Confusion Matrix：分析类别混淆。

## 与检测/分割的关系

分类训练得到的 backbone 可以迁移到检测和分割。目标检测中的类别分支，本质上也是局部区域或查询对象的分类问题。
