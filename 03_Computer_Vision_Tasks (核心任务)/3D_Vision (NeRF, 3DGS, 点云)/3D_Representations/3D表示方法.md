# 3D 表示方法

3D 表示决定模型如何存储和计算空间中的形状、外观和密度。不同表示适合不同任务。

## 常见表示

| 表示 | 内容 | 优点 | 局限 |
|------|------|------|------|
| 点云 | 一组 3D 点 | 采集直接、稀疏高效 | 无拓扑、表面不连续 |
| 网格 | 顶点、边、面 | 表面清晰、适合渲染 | 拓扑复杂、重建困难 |
| 体素 | 3D 栅格 | 规则结构、易卷积 | 分辨率受内存限制 |
| 深度图 | 每像素深度 | 与图像天然对齐 | 单视角，遮挡信息缺失 |
| SDF | 到表面的有符号距离 | 表面提取稳定 | 训练和采样成本较高 |
| Occupancy Field | 空间点是否被占据 | 表示灵活 | 表面精度依赖采样 |
| Radiance Field | 密度 + 颜色 | 适合新视角合成 | 渲染计算较重 |
| 3D Gaussian | 高斯点 + 颜色/透明度 | 实时渲染强 | 动态、编辑和压缩仍复杂 |

## 点云

点云通常来自 LiDAR、RGB-D 相机或多视图重建。

常见处理：
- 下采样
- 法线估计
- 聚类
- 配准
- 点云分割

## 网格

网格适合渲染、仿真和几何处理。

组成：
- vertices：顶点
- edges：边
- faces：面
- texture/material：纹理和材质

## 隐式表示

隐式表示用函数描述空间：

$$f_\theta(x, y, z) \rightarrow s$$

其中 $s$ 可以是：
- 占据概率
- SDF 距离
- 密度
- 颜色

优点：
- 连续分辨率
- 拓扑灵活
- 适合神经网络学习

## NeRF 表示

NeRF 学习：

$$F_\theta(x, d) \rightarrow (\sigma, c)$$

输入空间位置 $x$ 和观察方向 $d$，输出密度 $\sigma$ 和颜色 $c$。

## 3DGS 表示

3D Gaussian Splatting 用大量 3D 高斯表示场景，每个高斯包含：
- 位置
- 协方差
- 颜色
- 不透明度

它通过 splatting 渲染，通常比原始 NeRF 更快。
