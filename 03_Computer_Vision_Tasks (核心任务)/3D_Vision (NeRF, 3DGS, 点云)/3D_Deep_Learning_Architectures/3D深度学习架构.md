# 3D 深度学习架构

3D 数据没有统一的规则网格表示，因此 3D 深度学习架构通常围绕数据表示展开：体素、点云、网格和多视图。

## 主要输入形式

| 表示 | 形态 | 优点 | 局限 |
|------|------|------|------|
| 多视图图像 | 多张 2D 图像 | 可复用 2D CNN | 依赖视角覆盖 |
| 深度图 | 每像素深度 | 与图像对齐 | 单视角信息有限 |
| 体素 | 3D 网格 | 可用 3D CNN | 内存消耗大 |
| 点云 | 无序点集合 | 稀疏高效 | 缺少规则邻域 |
| 网格 | 顶点 + 面 | 表面表达精确 | 拓扑处理复杂 |

## 3D CNN

3D CNN 在体素网格上做三维卷积：

```text
Voxel Grid D×H×W
  ↓
3D Conv
  ↓
3D Feature Map
```

优点：
- 结构直观，类似 2D CNN。
- 适合医学体数据、规则体素场。

缺点：
- 计算和显存随三维分辨率立方增长。
- 稀疏空间浪费严重。

## PointNet

PointNet 直接处理无序点云。核心是对每个点共享 MLP，再用对称函数聚合：

$$f(\{x_i\}) = \gamma(\max_i h(x_i))$$

关键点：
- 点云无序，所以聚合函数必须对排列不敏感。
- max pooling 得到全局特征。
- 原始 PointNet 局部几何建模较弱。

## PointNet++

PointNet++ 引入层级局部区域：

```text
Sampling
  ↓
Grouping
  ↓
Local PointNet
  ↓
Hierarchical Features
```

它更适合处理局部结构、不同密度点云和分割任务。

## 稀疏卷积

稀疏卷积只在非空体素上计算，常用于自动驾驶点云检测。

代表方向：
- SparseConv
- SECOND
- VoxelNet
- CenterPoint

## 选择建议

- 医学体数据：3D CNN。
- 原始点云分类/分割：PointNet++。
- 自动驾驶 LiDAR 检测：体素化 + 稀疏卷积。
- 多相机场景：多视图特征融合或 NeRF/3DGS。
