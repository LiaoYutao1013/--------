# 神经渲染与重建

神经渲染把几何、外观和可微渲染结合起来，用神经网络或可学习表示生成新视角图像。

## 任务目标

给定多张图像和相机位姿，学习一个三维场景表示，使得从新视角渲染出的图像尽可能真实。

```text
Multi-view Images + Camera Poses
  ↓
Learn 3D Scene Representation
  ↓
Render Novel Views
```

## NeRF

NeRF 用 MLP 表示辐射场：

$$F_\theta(x, d) = (\sigma, c)$$

其中：
- $x$：三维空间点
- $d$：观察方向
- $\sigma$：体密度
- $c$：颜色

渲染通过体渲染积分完成：

$$C(r)=\int T(t)\sigma(r(t))c(r(t),d)dt$$

直觉：
- 沿相机射线采样很多点。
- 每个点预测颜色和密度。
- 按透明度累积成最终像素颜色。

## NeRF 的限制

- 原始训练和渲染速度慢。
- 对相机位姿质量敏感。
- 动态场景和反光材质较难。
- 显式几何提取不直接。

## 3D Gaussian Splatting

3DGS 用可学习的 3D 高斯替代 MLP 体场。

每个高斯包含：
- 位置
- 尺度和旋转
- 不透明度
- 球谐颜色系数

优势：
- 渲染速度快，适合实时新视角合成。
- 表示显式，更容易可视化和编辑。
- 训练通常比原始 NeRF 更快。

## SLAM 与重建

SLAM 关注同时定位与建图：

```text
Frame sequence
  ↓
Feature / Direct tracking
  ↓
Pose estimation
  ↓
Map update
  ↓
Loop closure
```

神经 SLAM 尝试用 NeRF、SDF 或 3DGS 作为地图表示。

## 学习路线

1. 先掌握 [[../3D_Geometry_Foundations/Camera Models|Camera Models]] 和相机位姿。
2. 再理解体渲染和射线采样。
3. 对比 NeRF 与 3DGS 的表示和渲染方式。
4. 最后看动态场景、可编辑场景和实时重建。
