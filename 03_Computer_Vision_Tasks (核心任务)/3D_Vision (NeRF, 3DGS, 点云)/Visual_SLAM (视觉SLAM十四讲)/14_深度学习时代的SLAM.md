# 第 14 讲：深度学习时代的 SLAM

## 学习模块的切入点

深度学习通常替换或增强某个模块，而不是自动消除几何约束：

| 模块 | 传统方法 | 学习增强 |
| --- | --- | --- |
| 特征与匹配 | ORB、SIFT、几何筛选 | SuperPoint、LightGlue、LoFTR |
| 深度与光流 | 双目 / 多视图 / 光度一致性 | 单目深度、光流、深度补全 |
| 位姿 | PnP、直接法、BA | 可学习匹配权重、端到端初始化 |
| 场所识别 | BoW | 全局图像检索描述子 |
| 地图表示 | 点、TSDF、网格 | NeRF、SDF、3DGS 等神经场 |

## 几何仍是约束

学习特征可提升可匹配性，但位姿仍需 RANSAC、重投影验证和 BA。端到端网络可能在训练分布内表现好，却因相机、光照或场景改变出现域偏移；几何残差提供可解释的失败信号。

## 神经地图

NeRF / SDF / 3DGS 可表示连续外观或几何，适合新视角合成与高保真重建。作为 SLAM 地图时，需要同时解决在线优化、实时渲染、位姿-地图耦合、动态物体与长期一致性。相关背景见 [[../Neural_Rendering_&_Reconstruction/神经渲染与重建|神经渲染与重建]]。

## 选择方法的准则

- 实时嵌入式定位：优先成熟的几何前端与轻量特征。
- 纹理弱、光照变化大：评估学习特征/匹配器，保留几何验证。
- 稠密可视化：考虑神经场或 3DGS，但先明确硬件预算与重建时延。
- 安全关键任务：需要不确定性、失效检测、数据闭环和跨场景验证。

## 阅读论文时的问题

1. 网络替换了 SLAM 的哪一个模块？输入和监督信号是什么？
2. 是否使用真值位姿、深度或预训练数据？
3. 如何保证几何一致性、尺度和回环后的地图更新？
4. 在哪些数据集、相机和实时条件下报告结果？
