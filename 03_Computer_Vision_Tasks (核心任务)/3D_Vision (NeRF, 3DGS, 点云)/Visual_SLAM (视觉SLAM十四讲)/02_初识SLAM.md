# 第 2 讲：初识 SLAM

## 定义与目标

SLAM（Simultaneous Localization and Mapping，同时定位与建图）要在未知（预设程度较低）的环境中同时完成确定位置与构建地图两个任务。

## 数学描述

对本体：
- 离散时间点$t_i$
- 离散位置信息$x_i$(向量！)

运动方程$$x_i = f(x_{i-1},u_i,w_i)$$
其中$u_i,w_i$分别是输入，噪声；

对观测：
- 离散路标（相机拍摄到的参考物）$y_j$
- 在$x_i$处观测到$y_j$

观测方程$$z_{k,j}=f(x_i,y_j,v_{k,j})$$

## 骨架

| 模块        | 主要职责      | 输出         |
| --------- | --------- | ---------- |
| 传感器与标定    | 图像采集、内外参  | 去畸变图像、标定参数 |
| 前端（视觉里程计） | 推算局部位姿    | 相对运动、局部地图点 |
| 后端        | 最小化多帧累积误差 | 优化轨迹与建图信息  |
| 回环        | 识别已访问地点   | 长程约束       |
| 建图        | 组织几何与语义信息 | 稀疏/稠密地图    |

## 子任务

- 定位：依赖建图
- 建图：依赖定位

由于两个子任务相互耦合，实际上是估算定位信息与地图信息，并将估算结果与真实情况间的误差最小化。

## 传感器选择

- **单目相机**：成本低、视野灵活；但深度信息丢失（因相机本质是对三维空间进行投影），初始化依赖视差。
- **双目相机**：由基线恢复尺度；远距离深度误差大，需精确双目标定。
- **深度相机**：直接得到近距深度；量程、室外强光与深度空洞受限。
- **视觉惯性**：IMU 补强快速运动与尺度；需要时间同步和偏置估计。

对于传统的定位建图，还有使用二维码、导轨等标记的方法，但不满足SLAM的要求（做了太多环境预设），SLAM更偏好相机、IMU等搭载在设备本体上的传感器。

## 常见评价指标

- ATE（Absolute Trajectory Error）：与真值对齐后的全局轨迹偏差。
- RPE（Relative Pose Error）：固定时间或帧间隔的相对位姿误差，反映漂移率。
- 还应报告：跟踪丢失次数、运行帧率、地图质量和硬件配置。
