# 第 3 讲：三维空间刚体运动

重点问题：实现世界坐标系（全局）、设备坐标系、相机坐标系间坐标的转换。

## 旋转与变换

三维旋转矩阵：

$$SO(3)=\{R\in\mathbb{R}^{3\times3}\mid R^TR=I,\det(R)=1\}$$

刚体变换：

$$T=\begin{bmatrix}R&t\\0^T&1\end{bmatrix}\in SE(3),\qquad p_c=Rp_w+t$$
这里通过更高维度（四维）的旋转来表示三维空间中的平动。
约定$T_{ab}$表示把$b$坐标系的点转到$a$坐标系。则 $T_{ac}=T_{ab}T_{bc}$，$T_{ba}=T_{ab}^{-1}$。

## 旋转表示的方法

|      | 优点         | 缺陷                   |
| ---- | ---------- | -------------------- |
| 旋转矩阵 | 作用点直接、无奇异点 | 9 个量但仅 3 自由度         |
| 欧拉角  | 直观         | 万向节死锁（奇异点），角顺序敏感     |
| 轴角   | 最小参数化      | 接近 $\pi$ 时处理需谨慎      |
| 四元数  | 紧凑、插值方便    | 需单位化；$q$ 与 $-q$ 同一旋转 |

旋转时，四元数优化了欧拉角存在的奇异点问题，但仅限于数学层面，实际的设备会因为机械结构限制，存在其他的死锁问题，需通过规划规避（但就方程式来看这个问题似乎不太重要？）

## 四元数

单位四元数 $q=[q_w,q_x,q_y,q_z]^T$ 表示旋转；组合使用四元数乘法。更新时不要直接对四元数做无约束加法，通常在李代数中用小扰动更新，再转换回四元数。

## Eigen 与 Geometry 模块应用

Eigen 是 C++ SLAM 工程中常用的线性代数库；几何类型位于 `Eigen/Geometry`。可直接表达向量、旋转和刚体变换。

```cpp
#include <Eigen/Core>
#include <Eigen/Geometry>

using Vec3 = Eigen::Vector3d;

const Vec3 p_w(1.0, 0.0, 2.0);             // 世界坐标点
const Vec3 t_cw(0.1, 0.0, 0.2);            // 世界系到相机系的平移
const double theta = 3.14159265358979323846 / 6.0;
const Vec3 axis = Vec3::UnitY();

Eigen::AngleAxisd aa(theta, axis);         // 轴角：角度用弧度
Eigen::Quaterniond q_cw(aa);               // 旋转的紧凑表示
q_cw.normalize();
Eigen::Matrix3d R_cw = q_cw.toRotationMatrix();

Eigen::Isometry3d T_cw = Eigen::Isometry3d::Identity();
T_cw.linear() = R_cw;
T_cw.translation() = t_cw;

Vec3 p_c = T_cw * p_w;                     // 等价于 R_cw * p_w + t_cw
Eigen::Isometry3d T_wc = T_cw.inverse();   // 相机系到世界系
```

### 类型与用途

| Eigen 类型 | 表示 | 在视觉 SLAM 中的常见用途 |
| --- | --- | --- |
| `Vector2d` / `Vector3d` | 二、三维列向量 | 像素坐标、三维点、平移、李代数增量 |
| `Matrix3d` | $3\times3$ 矩阵 | 旋转矩阵、相机内参、协方差 |
| `AngleAxisd` | 轴角 | 从“绕某轴旋转多少”构造旋转 |
| `Quaterniond` | 单位四元数 | 存储姿态、插值、与 IMU 姿态对接 |
| `Isometry3d` | $SE(3)$ 刚体变换 | 位姿、坐标变换、变换链组合 |

### 变换链与位姿方向

遵循本讲 $T_{ab}$ 的约定时，Eigen 中的组合顺序保持不变：

```cpp
Eigen::Isometry3d T_cb;  // b 系 -> c 系
Eigen::Isometry3d T_bw;  // w 系 -> b 系
Eigen::Isometry3d T_cw = T_cb * T_bw;

Vec3 p_c = T_cw * p_w;
```

`Isometry3d` 仅适用于旋转加平移；不要把带尺度的单目 Sim(3) 变换塞进其中。若需要缩放，使用 `Eigen::Affine3d` 或单独维护尺度，并在优化中采用合适的 Sim(3) 表示。

### SLAM 代码中的注意点

- `Quaterniond(w, x, y, z)` 的构造参数顺序是 **w、x、y、z**；但 `q.coeffs()` 返回的存储顺序是 **x、y、z、w**，和部分库交换数据时尤其容易出错。
- `AngleAxisd` 的旋转角是弧度，旋转轴应为单位向量。
- 仅用作旋转的四元数应保持单位长度；读取传感器或优化器输出后先检查并按需 `normalize()`。
- 固定尺寸的 Eigen 类型放进 STL 容器或类成员时，要留意对齐要求；在旧编译环境或特定 Eigen 配置中使用 `Eigen::aligned_allocator` / `EIGEN_MAKE_ALIGNED_OPERATOR_NEW`。

## 实践检查

- 坐标变换的乘法顺序是否匹配列向量约定？
- 单位：平移为米、旋转为弧度；不要混用角度。
- 优化后矩阵是否仍满足 $R^TR=I$？若直接优化矩阵，容易破坏该约束。
