# 第 13 讲：设计与实践

## 最小可行系统

建议先搭建可观测、可验证的单目或 RGB-D 管线：

```text
数据读取与标定 -> 特征/光流跟踪 -> RANSAC 位姿估计
-> 三角化或深度建点 -> 局部 BA -> 可视化与轨迹评估
```

先在公开数据集复现，再接入真实设备。每一步保存中间结果，避免只在最终轨迹出错时盲查。

## 模块接口

| 模块 | 输入 | 输出 |
| --- | --- | --- |
| Tracker | 图像、上一状态、局部地图 | 当前位姿、匹配与质量指标 |
| Local mapper | 关键帧、观测 | 新路标、局部 BA 结果 |
| Loop closer | 关键帧数据库 | 回环候选、验证结果、校正约束 |
| Viewer / Logger | 状态与地图 | 轨迹、点云、性能和诊断日志 |

## 工程原则

- 坐标系命名写入类型或变量名，例如 `T_cw`、`T_bc`，并在边界处断言。
- 标定、数据集路径、阈值通过配置管理；运行结果记录版本与参数。
- 前端、局部建图、回环线程共享数据时明确所有权和锁粒度。
- 把随机数种子、数据子序列和评价脚本纳入复现实验。

## 调试路径

1. 画匹配连线，确认匹配覆盖而非只集中于局部。
2. 投影地图点到图像，检查系统性偏移以定位标定/坐标系错误。
3. 画每帧内点数、重投影误差、关键帧频率，定位跟踪恶化位置。
4. 以 ATE/RPE 对比开关回环、开关 BA、不同传感器配置。

## 推荐练习

- 用已知内参完成两视图本质矩阵估计、位姿恢复与三角化。
- 用 PnP + RANSAC 跟踪 RGB-D 序列，并绘制轨迹。
- 对一段有闭环的序列构建位姿图，观察优化前后的漂移差异。
