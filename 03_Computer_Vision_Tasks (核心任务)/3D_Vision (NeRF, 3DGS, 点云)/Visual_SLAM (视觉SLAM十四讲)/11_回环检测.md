# 第 11 讲：回环检测

## 目标

当前相机可能回到已访问区域。识别这一事件并加入约束，才能消除长时间积累的漂移。回环不是“图像相似”就成立，必须经过几何验证。

## 典型流程

```text
当前关键帧
  -> 图像检索（BoW / 全局描述子）
  -> 时间一致性与候选筛选
  -> 特征匹配
  -> PnP / Sim(3) RANSAC 几何验证
  -> 加入回环边
  -> 位姿图优化与地图融合
```

## 场所识别

- BoW（词袋）：把局部描述子量化成视觉词汇，倒排索引实现高效检索。
- 全局描述子：NetVLAD、CosPlace 等对外观变化更有鲁棒性，但仍需几何验证。
- 排除与当前帧共视的邻近关键帧，避免把连续跟踪误判为回环。

## 验证策略

使用 PnP 或 Sim(3) 求相对关系，并检查内点数、内点空间分布、尺度一致性与重投影误差。重复结构、季节/光照变化、动态场景是主要误报来源。

## 回环后的工作

加入约束后，先做位姿图优化传播校正，再更新地图点和关键帧共视关系；必要时运行全局 BA。只改轨迹而不改地图会留下不一致。
