## 一条主线

```text
图像 / IMU
  -> 前端跟踪：匹配或直接法，估计相邻位姿
  -> 后端优化：联合优化关键帧、路标与传感器状态
  -> 回环检测：发现历史地点，加入长程约束
  -> 建图：输出稀疏、半稠密、稠密或语义地图
```

## 术语速查

| 术语 | 含义 |
| --- | --- |
| 位姿 $T_{cw}$ | 从世界坐标变换到相机坐标的刚体变换 |
| 路标 / Map point | 被多帧观测的三维点 |
| 关键帧 | 保留以约束优化与建图的代表性图像帧 |
| 重投影误差 | 三维点投影到图像后与实际观测的像素差 |
| 尺度漂移 | 单目系统无法从纯视觉恢复绝对尺度，且会累积误差 |

## 学习检查

1. 能写出 $p_c = T_{cw}p_w$，并说明 $T_{cw}$ 的方向。
2. 能区分视觉里程计的局部约束、后端的优化问题与回环的长程约束。
3. 能解释为什么单目初始化困难、为什么闭环后需要全局一致性优化。
4. 能为一段 RGB-D 或双目序列列出输入、输出和评估指标（ATE、RPE、轨迹可视化）。
