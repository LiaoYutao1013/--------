# 第 6 讲：非线性优化

## 前置知识：状态估计问题

SLAM 的核心是从带噪声的观测中推断不可直接观测的状态。记状态为 $x$（位姿、路标、速度、IMU 偏置等），测量为 $z$，则观测模型为：

$$z_i=h_i(x)+n_i,\qquad n_i\sim\mathcal{N}(0,\Sigma_i)$$

$h_i(\cdot)$ 是非线性测量函数。例如，对相机位姿 $T_{cw}$ 与地图点 $P_w$，像素观测为 $z=\pi(T_{cw}P_w)+n$。

估计要回答两个问题：

- **状态是什么**：本次优化哪些变量？例如仅当前帧位姿（PnP），或关键帧位姿加三维点（BA）。
- **信息从哪里来**：图像重投影、IMU、轮速计、回环、先验分别形成哪些残差和不确定性？

若有先验 $x\sim\mathcal{N}(\bar{x},\Sigma_0)$，最大后验（MAP）估计为：

$$x^*=\arg\min_x\frac{1}{2}\|x-\bar{x}\|_{\Sigma_0^{-1}}^2+
\frac{1}{2}\sum_i\|z_i-h_i(x)\|_{\Sigma_i^{-1}}^2$$

无先验时退化为最大似然（MLE）。信息矩阵 $\Omega_i=\Sigma_i^{-1}$ 表示测量可信度：噪声小的测量权重更大。位姿属于 $SE(3)$ 流形，迭代时应以李代数增量更新，而不是直接相加；见 [[04_李群与李代数|李群与李代数]]。

## 非线性最小二乘

将每项误差写成残差 $r_i(x)$，得到标准目标：

$$F(x)=\frac{1}{2}\sum_i r_i(x)^T\Omega_i r_i(x)$$

视觉 BA 的残差为重投影误差：

$$r_{ij}=z_{ij}-\pi(T_iP_j)$$

它之所以非线性，来自透视除法、旋转参数化和可能的畸变模型。优化不是一次求出闭式解，而是在当前估计附近反复计算增量 $\Delta x$：

$$x\leftarrow x\boxplus\Delta x$$

对普通向量，$\boxplus$ 是加法；对位姿，常用 $T\leftarrow\exp(\Delta\xi^\wedge)T$（左扰动）或对应的右扰动。约定必须与雅可比一致。

### 线性化与正规方程

在 $x$ 附近一阶展开：

$$r(x+\Delta x)\approx r(x)+J\Delta x,\qquad J=\frac{\partial r}{\partial x}$$

将所有残差堆叠并吸收权重后，记 $H=J^TJ$、$b=-J^Tr$，线性子问题为：

$$H\Delta x=b$$

实际求解应使用 Cholesky、QR 或稀疏线性求解器，**不要显式求 $H^{-1}$**。SLAM 中每个测量只连接少量变量，$H$ 通常高度稀疏。

## 牛顿法（Newton）

Newton 法直接对目标函数二阶泰勒展开：

$$F(x+\Delta x)\approx F(x)+g^T\Delta x+\frac{1}{2}\Delta x^TH\Delta x$$

其中 $g=\nabla F(x)$，$H=\nabla^2F(x)$，更新满足：

$$H\Delta x=-g$$

对平方残差，精确海森矩阵为：

$$\nabla^2F=J^TJ+\sum_i r_i\nabla^2r_i$$

优点是接近极小值时可快速收敛；缺点是二阶残差导数难算、代价高，且远离最优点时 $H$ 可能非正定，步骤不一定下降。因此纯 Newton 法在视觉 SLAM 中较少直接使用。

## 高斯-牛顿法（Gauss–Newton）

高斯-牛顿忽略 $\sum_i r_i\nabla^2r_i$，即以：

$$H\approx J^TJ,\qquad J^TJ\Delta x=-J^Tr$$

来求增量。这正是上面的正规方程。当残差已较小、初值合理时，该近似有效且通常收敛很快；BA、PnP 位姿细化和局部图优化均常使用它。

它的限制是：初值差、强非线性或错误数据关联时，线性化模型会不可靠，可能出现代价上升、矩阵病态或发散。改善手段包括金字塔/粗到细初始化、RANSAC、鲁棒核与阻尼。

## 列文伯格－马夸尔特法（Levenberg–Marquardt, LM）

LM 在高斯-牛顿的近似海森矩阵上加入阻尼：

$$\left(J^TJ+\lambda D\right)\Delta x=-J^Tr$$

其中 $D$ 可取 $I$ 或 $\operatorname{diag}(J^TJ)$，$\lambda>0$ 是阻尼系数。

- $\lambda$ 很小时，LM 接近高斯-牛顿，收敛快。
- $\lambda$ 很大时，更新接近小步梯度下降，稳定但慢。
- 实现中根据实际代价下降与线性模型预测下降的比值调整 $\lambda$：接受有效步骤则减小阻尼，拒绝步骤则增大阻尼并重试。

LM 是视觉 BA 和图优化中常见的默认选择；它并不能修复错误匹配或错误坐标系，只能提高数值迭代的稳健性。

## BA、舒尔补与鲁棒核

Bundle Adjustment 联合优化相机位姿和路标点。每个观测只连接“一帧相机 + 一个三维点”，因此雅可比和海森矩阵具有块稀疏结构。舒尔补先消去路标变量，再求相机增量，可大幅降低大型 BA 的求解开销。

真实匹配含外点，常将平方损失替换为鲁棒代价：

$$\min_x\sum_i\rho\left(r_i(x)^T\Omega_i r_i(x)\right)$$

Huber 核在小残差时保留二次损失、在大残差时降低增长速度；Cauchy 核对大残差抑制更强。鲁棒核应与 RANSAC 配合：RANSAC 先移除明显错误模型，鲁棒核再减小残余异常值影响。

## Ceres：以残差块组织优化

Ceres Solver 适合把问题描述为“参数块 + 残差块 + 损失函数”。它支持自动求导、数值求导和解析雅可比，对小中型 BA、标定和多传感器参数估计尤其方便。

下面的残差块描述一个重投影观测；四元数按 Ceres 默认顺序 `[w, x, y, z]` 存储：

```cpp
#include <ceres/ceres.h>
#include <ceres/rotation.h>

struct ReprojectionError {
  ReprojectionError(double u, double v, double fx, double fy,
                    double cx, double cy)
      : u_(u), v_(v), fx_(fx), fy_(fy), cx_(cx), cy_(cy) {}

  template <typename T>
  bool operator()(const T* const q_cw, const T* const t_cw,
                  const T* const p_w, T* residuals) const {
    T p_c[3];
    ceres::QuaternionRotatePoint(q_cw, p_w, p_c);
    p_c[0] += t_cw[0]; p_c[1] += t_cw[1]; p_c[2] += t_cw[2];
    residuals[0] = T(fx_) * p_c[0] / p_c[2] + T(cx_) - T(u_);
    residuals[1] = T(fy_) * p_c[1] / p_c[2] + T(cy_) - T(v_);
    return true;
  }

  double u_, v_, fx_, fy_, cx_, cy_;
};

ceres::Problem problem;
// q_cw = {w, x, y, z}; t_cw 和 point_w 分别为 3 维数组。
problem.AddParameterBlock(q_cw, 4, new ceres::QuaternionManifold());
problem.AddResidualBlock(
    new ceres::AutoDiffCostFunction<ReprojectionError, 2, 4, 3, 3>(
        new ReprojectionError(u, v, fx, fy, cx, cy)),
    new ceres::HuberLoss(1.0), q_cw, t_cw, point_w);

ceres::Solver::Options options;
options.linear_solver_type = ceres::SPARSE_SCHUR;  // BA 常用
ceres::Solver::Summary summary;
ceres::Solve(options, &problem, &summary);
```

要点：为姿态配置流形（否则四元数单位约束会被破坏）；对固定参考帧调用 `SetParameterBlockConstant` 消除规范自由度；大型 BA 选择 `SPARSE_SCHUR` 等稀疏求解器。不同 Ceres 版本的流形 API 有差异，旧版本可能使用 `QuaternionParameterization`；`Eigen::Quaterniond::coeffs()` 的内存顺序为 `[x,y,z,w]`，不能直接当作上面 Ceres 数组传入。

## g2o：以图模型组织优化

g2o（General Graph Optimization）将变量表示为**顶点**，测量/先验表示为**边**，天然贴合位姿图、BA 与因子图式 SLAM。

| SLAM 对象 | g2o 对应 |
| --- | --- |
| 相机位姿、路标、速度或偏置 | `Vertex` |
| 重投影、IMU、里程计、回环、先验 | `Edge` |
| 测量值 | `Edge::measurement` |
| 信息矩阵 $\Omega$ | `Edge::information` |
| Huber / Cauchy 核 | `RobustKernel` |

典型 BA 建图流程如下（具体类型与头文件随 g2o 版本和自定义顶点而不同）：

```cpp
g2o::SparseOptimizer optimizer;
optimizer.setAlgorithm(algorithm);  // 例如稀疏 BlockSolver + LM

// 1. 添加顶点：关键帧位姿 VertexSE3Expmap、路标 VertexSBAPointXYZ。
//    固定首个位姿，消除全局坐标系自由度。
pose_vertex->setId(frame_id);
pose_vertex->setEstimate(initial_pose);
pose_vertex->setFixed(frame_id == 0);
optimizer.addVertex(pose_vertex);

// 2. 添加观测边：EdgeProjectXYZ2UV 连接一个路标顶点和一个位姿顶点。
edge->setVertex(0, point_vertex);
edge->setVertex(1, pose_vertex);
edge->setMeasurement(Eigen::Vector2d(u, v));
edge->setInformation(Eigen::Matrix2d::Identity() / sigma2);
edge->setRobustKernel(new g2o::RobustKernelHuber);
optimizer.addEdge(edge);

// 3. 求解并依据卡方误差剔除外点后再优化。
optimizer.initializeOptimization();
optimizer.optimize(10);
```

使用 g2o 时需要为每种边正确实现残差、雅可比和 `computeError()`，并保证顶点的位姿更新规则与 $SE(3)$ 扰动约定一致。它对大规模稀疏图优化很直接，但自定义模型的实现工作通常比 Ceres 的自动求导更多。

### Ceres 与 g2o 的选择

| 需求 | 更适合的选择 | 原因 |
| --- | --- | --- |
| 快速构建自定义残差、标定、自动求导 | Ceres | 参数块与残差块灵活，自动求导成熟 |
| 位姿图、经典 BA、已有图优化框架 | g2o | 顶点—边抽象与稀疏图结构直接对应 |
| 需要学习两者 | 先 Ceres，后 g2o | 先理解残差和流形，再理解图的稀疏结构 |

无论使用哪个库，都要先定义清楚状态、坐标系、观测模型、噪声和初值；优化器只能高效求解你表达出来的问题。

## 调试顺序

1. 用数值差分核验解析雅可比；自动求导也要用小规模案例核验残差方向。
2. 检查初始代价、每轮代价、步长、有效观测数和被拒绝的 LM 步数。
3. 检查量纲与信息矩阵，避免像素和米混合而未加权。
4. 固定一个参考位姿或加入先验，消除规范自由度。
5. 先用无外点的合成数据验证，再加入 RANSAC、鲁棒核和真实数据。
