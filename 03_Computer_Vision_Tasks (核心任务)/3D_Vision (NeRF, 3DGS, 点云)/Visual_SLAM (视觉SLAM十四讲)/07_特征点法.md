# 第 7 讲：特征点法

## 特征流程

```text
检测关键点 -> 计算描述子 -> 最近邻匹配 -> 比率/互检筛选
-> RANSAC 几何验证 -> 三角化或 PnP -> 局部优化
```

## 检测器与描述子

- ORB：FAST 角点 + BRIEF 描述子，二进制描述子可用 Hamming 距离，实时系统常用。
- SIFT：尺度、旋转鲁棒性较强，浮点描述子计算更重。
- 学习特征：SuperPoint、D2-Net 等可提升重复纹理、弱纹理下的匹配，但部署成本和域偏移要评估。

## 匹配过滤

- 最近邻距离小不代表正确；用 Lowe 比率测试、交叉验证过滤歧义匹配。
- 用 RANSAC 估计基础矩阵、本质矩阵、单应或 PnP，保留内点。
- 模型取决于场景：纯旋转/平面更符合单应；有视差的刚体场景使用本质矩阵。

## 数据关联的本质

前端最重要的不是“特征数量”，而是跨帧把同一物理点正确连起来。错配会被后端放大为错误约束，导致轨迹跳变或地图撕裂。

## 实践指标

记录关键点数、匹配数、RANSAC 内点率、空间分布和跟踪寿命。只看匹配总数会忽视特征集中在单一区域或动态物体上的风险。
