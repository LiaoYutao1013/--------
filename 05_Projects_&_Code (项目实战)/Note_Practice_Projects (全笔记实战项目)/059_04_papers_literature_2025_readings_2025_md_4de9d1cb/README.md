# 2025 论文阅读记录：实战项目

来源笔记：`04_Papers_&_Literature (论文精读)/2025_Readings/2025论文阅读记录.md`

## 项目目标

构建论文阅读追踪器，对应《2025 论文阅读记录》的精读记录。

该项目的程序不读取原始笔记，配置和代码都在当前项目目录内，可独立运行。

## 练习切入点

- 快速记录模板
- 论文标题
- 待读列表
- 阅读原则

## 运行

```bash
python main.py
```

运行后会生成：

- `artifacts/result.json`

- 把合成数据替换成真实数据。
