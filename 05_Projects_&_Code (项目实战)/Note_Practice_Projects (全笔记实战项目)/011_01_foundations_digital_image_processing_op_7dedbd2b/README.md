## 项目目标

搭建轻量结构分析器，统计《MobileNet》相关模块的形状和参数量。

该项目的程序不读取原始笔记，配置和代码都在当前项目目录内，可独立运行。

## 练习切入点

- 围绕主题完成一次最小可运行实验

## 运行

```bash
python main.py
```

运行后会生成：

- `artifacts/result.json`
