# 开源项目研究方法

开源项目研究的目标是理解一个成熟项目如何组织模型、数据、训练、评估和部署，而不是只看某个函数。

## 推荐阅读顺序

```text
README
  ↓
配置文件
  ↓
数据集接口
  ↓
模型构建
  ↓
训练入口
  ↓
损失函数
  ↓
评估和推理
  ↓
导出和部署
```

## 重点问题

- 配置系统如何组织模型和训练参数？
- Dataset 和 DataLoader 如何输出 batch？
- 数据增强在哪里执行？
- 模型由哪些模块拼装？
- 损失函数输入输出是什么？
- 指标如何计算？
- checkpoint 如何保存和加载？
- 推理和训练路径有什么差异？

## 推荐项目

| 项目 | 方向 | 阅读重点 |
|------|------|----------|
| Ultralytics YOLO | 检测/分割/姿态 | 训练入口、模型 YAML、增强、导出 |
| MMDetection | 检测 | 配置系统、registry、runner |
| Detectron2 | 检测/分割 | 数据集注册、ROI heads |
| Segment Anything | 分割 | prompt encoder、mask decoder |
| OpenMMLab 3D | 3D 检测 | 点云数据流和坐标系 |
