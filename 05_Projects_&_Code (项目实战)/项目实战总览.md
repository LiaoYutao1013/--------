# 项目实战总览

项目实战目录用于把笔记中的理论变成可运行、可评估、可复盘的工程项目。

## 模块结构

| 模块 | 作用 | 入口 |
|------|------|------|
| 竞赛记录 | 记录 Kaggle/天池/比赛方案和复盘 | [[./Competition_Kaggle (竞赛记录)/竞赛项目记录模板|竞赛项目记录模板]] |
| 开源项目研究 | 阅读 YOLO、Detectron2、MMDetection 等项目 | [[./Open_Source_Labs (开源项目研究)/开源项目研究方法|开源项目研究方法]] |
| 模型部署 | ONNX、TensorRT、量化、边缘推理 | [[./Deployment (模型部署：TensorRT, ONNX)/模型部署总览|模型部署总览]] |
| 全笔记实战 | 为每篇笔记生成一个可运行项目 | [[./Note_Practice_Projects (全笔记实战项目)/README|全笔记实战项目]] |
| 模型训练与视觉任务 | 练习分类、检测、分割、自监督和训练报告 | [[./Training_and_Vision_Tasks (模型训练与视觉任务)/README|模型训练与视觉任务]] |

## 一个完整项目应包含

```text
问题定义
  ↓
数据分析
  ↓
Baseline
  ↓
模型改进
  ↓
训练与评估
  ↓
错误分析
  ↓
部署或复现报告
```

## 推荐项目

- 自定义数据集训练 YOLO。
- 对比不同数据增强对小目标检测的影响。
- 使用 U-Net 完成医学/工业分割。
- 将 PyTorch 模型导出 ONNX 并用 TensorRT 加速。
- 阅读一个开源检测框架并画出训练流程。
- 从零训练分类器，再迁移到冻结特征、微调和自监督预训练。
- 建立检测、分割任务的 baseline，并输出训练报告和错误分析。
- 使用 CMake 构建一个跨平台 C++ 视觉推理程序，并完成安装打包。
